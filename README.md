**顾清影（GQY）** 是一个住在你自己电脑上的 AI 助手。她能陪你聊天，也能帮你读代码、改文件、跑命令、处理日常事务。会话、记忆和授权都留在本机，边界由你决定。

GQY v2 是对 [gqy-agent（v1）](https://github.com/yxxbc/gqy-agent) 的一次彻底重构。v1 证明了这条路走得通，但它的底层已经难以继续维护。v2 用纯 Rust 重新打地基，目标是一个下载即用的单文件程序。

> [!IMPORTANT]
> **项目状态：设计阶段，暂时不能安装使用。**
> 仓库里目前只有设计文档、施工方案和工程规范，还没有可运行的程序。想现在就用顾清影，请继续使用 [v1](https://github.com/yxxbc/gqy-agent)。v2 正式发布时会提供 v1 数据导入工具（见[路线图](#路线图)）。

## 她会是什么样子

以下都是 v2 的**设计目标**，不是已有的功能。

- **一个文件，开箱即用**：核心是单一可执行文件，不需要预装 Python、Node.js 或其他运行环境。
- **终端和网页都能用**：
  - 终端界面（TUI）；
  - 内嵌在程序里的 Web 控制台，手机、平板也能访问；
  - 可选的桌面应用。
  - 三者操作的是同一份会话，在一处开始的对话，可以在另一处接着聊。
- **长时间运行也稳定**：会话可以连续好几天，上下文可以到十万 token 级别。内存、延迟和费用都应当保持可预测。
- **省钱的长对话**：请求严格按“只追加”的方式组织，尽量命中模型供应商的前缀缓存。v1 在长会话里实测命中率达到 99.9%。
- **你说了算**：
  - 能力分档：只读、工作区读写、完全；
  - 有后果的操作会先问你；
  - 命令在沙盒里执行，沙盒无法生效时宁可拒绝执行。
- **记录不会丢**：
  - 数据存放在本机；
  - 升级只做增量迁移；
  - 导入 v1 数据时，先预演、再核对、最后才写入。
- **多台设备互相帮忙**：每个应用既是客户端，也是服务端，不依赖中心服务器。
- **伴侣回归**：人格、记忆，以及 QQ、iMessage 等聊天平台，会在内核稳定后陆续回归。

## 平台

| 平台 | 计划 |
| --- | --- |
| Linux | 完整支持 |
| macOS（Apple 芯片） | 完整支持 |
| Windows | 能编译，功能不完整；缺少的能力（例如沙盒）会直接拒绝执行 |

## 路线图

| 里程碑 | 你能做什么 | 状态 |
| --- | --- | --- |
| 设计与施工方案 | 阅读设计，参与讨论 | 进行中 |
| M1 最小闭环 | 在终端里和模型完成一轮对话，记录落在本机 | 未开始 |

| M5 多设备 | 设备配对、互相提供能力、按需同步 | 未开始 |
