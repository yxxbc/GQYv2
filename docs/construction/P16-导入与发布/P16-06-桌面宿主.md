## 目标

`apps/desktop` 的 Tauri v2 宿主成立：启动尝试 `<data>/run/daemon.lock`——拿到则内嵌模式：进程内调用 `gqy_daemon::assemble_daemon`（与 `gqy daemon run` 同一函数），同时开 UDS（TUI、`gqy ask` 可连入），HTTP 监听遵配置；被占用且 UDS `ping` 成功则客户端模式：WebView 经宿主转发访问该 daemon；锁被占用但 ping 失败 → 报错并提示 `gqy daemon status`。WebView 访问 API 按 Q-15-5 先验证方案 A（`gqy://` 自定义协议转发到进程内 Router / UDS，需验证 SSE 流式），不支持则回落 B（`127.0.0.1:0` 回环 + 一次性令牌）。`info.features` 含 `desktop`；关窗默认最小化到托盘（`desktop.close_to_tray`），退出菜单执行 02 §9 停机；内嵌模式崩溃后锁随进程释放、下次启动按 02 §9 恢复非终态运行；打包体积与常驻内存实测写回 15 §10.3（参考值不是验收承诺）。

## 范围

- 做：
  - 模式判定（锁 + UDS ping）、内嵌组装与客户端模式；UDS 对外可用。
  - 托盘 / 关窗 / 退出停机；崩溃恢复联测。
  - WebView 传输（A 或 B）与一次性令牌（B 时 scope 限次启动）；`desktop.api_transport` 配置。
  - 体积 / 内存实测与 15 §10.3 回填。
- 不做：
  - 自动更新；安装器 / 签名 / 公证；业务逻辑分叉（前端同一产物，15 §10.3）；多窗口。

## 测试与守护

- **模式**：先起 `gqy daemon run` 再起桌面 → 客户端模式（不双写、不双开 UDS）；锁被占且 ping 失败 → 明确报错提示 `gqy daemon status`（去掉分支，红）。
- **停机**：退出菜单触发 02 §9；进程退出后锁释放；内嵌崩溃（kill -9）后重启恢复非终态运行（联测记录）。
- **传输**：方案 A 流式成立或回落 B 有测试（令牌一次性、scope 限次启动）；去掉回落分支，红。
- **features**：`/info.features` 含 `desktop`；非桌面进程不含。
- 先红后绿对照（PR 贴输出）：去掉「客户端模式」分支一次。
