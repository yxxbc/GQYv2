## 目标

前端骨架与门禁同时落地：`src/` 按 `core / state / widgets / features / app` 分层；`cargo xtask web check` 增加分层与体积检查（词法扫描 import、附加规则 + 违规样例自测）；`styles/tokens.css` 是字号 / 颜色 / z-index 的唯一来源；应用壳能启动、登录、显示开发横幅。做完之后，一条违规 import 或一次 `innerHTML` 越界都会在 CI 里报红，且报错格式与 `cargo xtask arch` 一致。

## 范围

- 做：
  - 目录与空位照 15 §4（`core/`、`state/`、`widgets/`、`features/`、`app/`；`index.html`、`styles/`、`dist/` 忽略）。
  - app 启动：拉 `GET /info`（features、CSRF 值）→ 无会话 → 配对界面（`#pair=<code>` 直接提交换登录，13 §8.3）→ 进入壳；`web_dir_override` 时顶部开发横幅。
  - `core/api/`：唯一的 `fetch` 封装（本单先 http + login；SSE 在 P10-05）；CSRF 头与统一错误类型；`core/dom/safe.ts` 的 `SafeHtml` 品牌类型与 `innerHTML` 唯一出口；`core/i18n` 骨架（界面文案走 i18n）。
  - `styles/tokens.css`：字号 / 颜色 / 层级变量；`index.html` 无内联脚本与样式（CSP 口径）。
  - `xtask/src/web/layers.rs`：词法扫描器（正确跳过字符串、注释、模板字面量）抽取 `import … from`、`export … from`、`import('…')`；相对路径 → 层映射；规则：层序表、`fetch` / `EventSource` / `WebSocket` 仅 `core/api/`、`innerHTML` 仅 `core/dom/safe.ts`、生成类型同名声明禁止、CSS 变量规则（`z-index` / 颜色 / 字号字面量禁止）；输出格式照 15 §4.2；无白名单。
  - 检查器自测：违规样例（features 互引、`fetch` 出现在 `features/`、`innerHTML` 越界、CSS 字面量、重复类型名）逐条报红；去掉任一规则对应测试红。
  - `cargo xtask web check` 汇总类型 + 分层 + 体积；CI 设为必需检查（19 §6.1 第 12 项）。
- 不做：
  - 对话与事件流（P10-05）、设置页（P10-06）、浏览器测试（P10-07）、markdown 渲染（P10-05 的 `core/markdown`）。

## 实施步骤

（L 单：每一步都能单独编译通过。）

1. 骨架目录与 tsconfig 对齐；体积门禁接入。
2. `core` 三件（api / safe / i18n）与 `tokens.css`。
3. `layers.rs` 扫描器 + 边界单测（注释中的 import、字符串中的 `from`、动态 import）。
4. 附加规则 + 违规样例自测。
5. app 启动与登录门（配对码）；开发横幅。
6. CI 接线；`cargo xtask check --fast`、`cargo test -p xtask`；提交：`feat(web): 前端分层骨架与层序门禁`。

## 测试与守护

- **扫描边界**：注释 / 字符串 / 模板字面量里的伪 import 不误报，动态 import 不漏报（各一条红线）。
- **规则各自区分**：五条违规样例逐条报红；删任一规则 → 对应样例测试红（门禁自身要有区分能力，19 §6.1）。
- **输出格式**：与 `cargo xtask arch` 一致（15 §4.2 示例串）；无白名单（构造“既违规又看似合理”的样例，仍红）。
- **登录门**：无 cookie → 显示配对输入；`#pair=` 合法码 → 换 cookie 进壳；会话过期（401）→ 回配对界面（15 §11）。
- **体积**：`.ts` / `.css` 超线样例报红（与 `xtask size` 同阈值，19 §6.1 第 6 项）。
- **同名校验**：手写文件声明与生成类型同名接口 → 红。
- 先红后绿对照（PR 贴输出）：去掉 `fetch` 出口规则、去掉 token 规则各一次。

## 风险与回退

- **词法扫描器不做完整 JS 解析**：边界靠单测钉住；出现误报先改扫描器而不是加白名单（15 §4.2 无白名单）。
- **tsconfig 与生成类型路径**：必须与 P10-02 的输出一致，避免隐式解析到旧文件。
- **回退**：检查器可单独 revert（`web check` 退回类型检查）；骨架目录保留空实现，页面回到占位。
