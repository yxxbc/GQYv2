## 目标

M3 的收口单：浏览器端测试（WebDriver）跑通首批场景；前端单元测试（归约器、resync、消毒）在同一浏览器会话中运行并把结果以 JSON 回传、并入 `cargo xtask test` 报告；M3 口径在 `tests/e2e/m3.sh` 中逐条可断言——同一二进制内嵌控制台、局域网外默认不可访问、TUI 与 Web 同时观察同一会话事件一致。

## 范围

- 做：
  - `tests/web/` 骨架：临时数据目录启动 daemon（mock 供应商）→ 经 UDS 取一次性配对码 → 浏览器打开 `/#pair=<code>` → 执行场景（15 §9）。
  - 场景（首批）：登录；发送消息并看到流式输出；审批抽屉允许 / 拒绝；断网 / resync（`stream.resync_required`）；设置页字段完整性；XSS 注入不执行（全局标志）；TUI 与 Web 同会话事件一致（M3）。
  - 运行条件：需要 `GQY2_WEBDRIVER_URL`（例如本机 `chromedriver --port=9515`）；未设置时用例标 `#[ignore = "needs:webdriver"]`，报告中显式“跳过（缺少 WebDriver）”，不计为通过（19 §5）。
  - 前端单测页：归约器、resync 状态机、markdown 消毒打包成一个测试页，同一浏览器会话内运行、JSON 回传、统一进报告（Q-15-3 按推荐先行）。
  - `tests/e2e/m3.sh`：release 构建同一二进制 → 内嵌控制台可达；未开启局域网时非回环地址连接被拒；TUI（headless 驱动）与 Web 同时观察同一会话，逐条事件一致。
  - Q-15-2 按推荐先行：`fantoccini`；driver 封装在 `tests/web/driver.rs` 一处，拍板换库只改这层。
  - 收尾：`CHANGELOG.md` 的 `[Unreleased]`；施工图 `plan-data` 状态与「每一步的图」补 M3 一节。
- 不做：
  - 桌面宿主与 Tauri（P16）、`GQY2_REQUIRE_WEB` 的 release CI 接线（P16-05）、多标签共享流（Q-15-4）。

## 测试与守护

- **跳过语义**：无 `GQY2_WEBDRIVER_URL` 时报告显式“跳过（缺少 WebDriver）”（把跳过算成通过，测试红；19 §5）。
- **场景各自区分**：去掉 Web 侧 resync 处理 → resync 场景红；去掉消毒 → XSS 场景红（全局标志被触发）；审批方向改错 → 允许 / 拒绝断言红。
- **一致性（M3）**：同一会话 TUI 与 Web 的转录条目序列逐条相同（共享夹具 + 实时事件双观察；改一侧归约，场景红）。
- **单测页结果**：回传 JSON 含每个用例名与结果；空结果或解析失败 → 门禁红（“没测到”不算过）。
- **端口口径**：未开启局域网时，非回环地址连接被拒（M3 口径）。
- **resync 死循环**：预算耗尽后不再自动重连（v1 前科的回归断言）。
- 先红后绿对照（PR 贴输出）：把跳过改成通过、去掉一致性断言各一次。

## 验收流程

```sh
cargo xtask web check
chromedriver --port=9515 &                                    # 本地 WebDriver
GQY2_WEBDRIVER_URL=http://127.0.0.1:9515 cargo xtask test --include-ignored=webdriver
tests/e2e/m3.sh                                               # release 内嵌 + 局域网默认不可达 + TUI×Web 一致
# 用户环境：cargo xtask web build --release → gqy web（或 TUI /web）→ 浏览器登录 →
#   同时开 TUI 与浏览器观察同一会话 → 事件一致；断网 → 横幅与 resync
```

## 风险与回退

- **WebDriver 与浏览器版本匹配**：driver 封装一处处理；失败信息含期望版本与获取方式（Q-15-2 备选 `chromiumoxide`）。
- **CI 作业安装步骤易碎**：Linux 作业设 `GQY2_WEBDRIVER_URL` 使场景真实执行；失败时打印 driver 日志；其它平台缺 driver 时显式跳过。
- **Q-15-3 备选未采用**：浏览器单测页是设计推荐；若最终改选 xtask 内嵌 JS 引擎，先并入 15 §9 再实现。
- **回退**：`tests/web/` 与 `m3.sh` 是新文件；revert 后 M3 退回手工验收清单，产品代码不受影响。
