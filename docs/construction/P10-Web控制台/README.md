# P10 · Web控制台

> 状态：【规划】。本阶段把 15 号设计落成内嵌 Web 控制台：esbuild 与 tsgo 工具链（零 Node）、TS 类型生成、资源内嵌与开发目录、前端分层骨架与层序门禁、对话视图与事件流、由配置 schema 生成的设置页，并收口 **M3 Web**。
> 创建：AI 助手（Cline 会话），2026-09-28。改动本文件时，按根 `AGENTS.md` 规矩 7 更新这一行：写清谁改的、什么时候改的。

## 阶段目标

（与施工图 `plan-data` 同文）esbuild 与 tsgo 工具链、TS 类型生成、内嵌与开发目录、应用骨架、对话、设置、浏览器测试。做完之后：

- 同一个二进制内嵌 Web 控制台，局域网外默认不可访问（00-施工总纲 §2 的 M3 口径）；
- 运行时与 `cargo` 用户都不需要 Node：esbuild 与 tsgo 都是固定版本 + 校验和的独立二进制，由 `cargo xtask` 下载校验（15 §3）；
- 前端不持有第二份事实：API 类型来自 `gqy-protocol` 生成；设置页由配置 schema 渲染，没有默认值字面量；命令表来自 `GET /commands`（15 §1）；
- 前端也有分层门禁：`cargo xtask web check` 检查层序、IO 出口、`innerHTML` 出口、CSS token 与体积（15 §4.2，19 §6.1 第 12 项）；
- 事件归约与 TUI 同组夹具、同一语义；resync 按 13 §6.4 的预算执行（15 §5、14 §13）；
- 浏览器端测试把首批场景自动化：登录、流式、审批、resync、设置完整性、XSS 不执行、TUI 与 Web 一致性（15 §9）。
