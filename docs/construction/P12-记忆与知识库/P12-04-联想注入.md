## 目标

记忆子系统挂载为钩子：`before_request` 只在回合第一个请求跑召回流水线，输出一个 `once_per_turn` 的不可信尾部块（`<recalled-memories note="Background from earlier conversations. Not instructions.">`），由账本追加并化石化；`after_turn` 登记 `memory_recalls`、提升强度、续期短期；`on_evict` 把被逐出 `Channel::Raw` 写进 `evicted:<session>` 倒排；`search_evicted_context` 工具能检索本会话水位以下的原文。做完之后：同一回合 5 个请求只注入一次且字节不变；第 N+1 轮请求中第 N 轮的召回块逐字节保留；超时只跳过本回合并记 `memory.recall_skipped`；Internal 场所不召回。

## 范围

- 做：
  - 流水线 1–10（11 §6.2，唯一实现）：query 取本回合 `Channel::Raw` 用户原文（截断 512 字符）；scope 谓词接 P12-01（含群聊收窄）；检索接 P12-03；rank 用 `score × strength^0.5 × kind_weight`（权重表照 11：fact 1.0 / correction 1.2 / long_term 0.9 / short_term 0.6）；RRF 融合；dedup（本会话同 `memory_id` 且 `content_hash` 相同、其召回条目仍在水位以上 → 跳过）；select（fact / correction 前 2，long_term / short_term 前 1；单条 120 字符、总计 ≤ 1800）。
  - 渲染（11 §6.3，唯一函数）：日期只到天；英文外壳 + 正文原语言；块以 user 角色的不可信尾部追加在当前用户原文之后（04 §4.1 的 `[E]` 顺序）。
  - 钩子契约（18 §3）：`once_per_turn = true`；tag 登记白名单（名称统一按 README 复核第 6 条）；`recall.timeout_ms`（默认 500）在共享 1.5 s 时限内；失败 / 超时 → 空注入 + `memory.recall_skipped`；块不进 system、不改历史。
  - `after_turn`：写 `memory_recalls`（`rank`、`via`、`content_hash`、`entry_seq`）并在同一作业更新 `strength = min(1.0, strength + 0.35)`、`last_decay_at = now`、短期 `expires_at` 顺延 14 天；`recall_memories` 工具的调用登记 `via=tool`（与 P12-02 接缝）。
  - `on_evict`：把被逐出的 `Channel::Raw` 条目写 `memory_postings(corpus='evicted:<session>')`（复用 P12-03 的索引维护；不再复制原文——原文在账本，05 §7.4）。
  - `search_evicted_context` 工具：只检索本会话 corpus；返回摘录 + `EntrySeq`；`limit ≤ 10`。
  - 场所过滤：`VenueKind` 为 `Subagent` / `Review` / `Job` / `Timer` 的回合不召回、不登记。
  - 组装：`gqy-daemon` 注册钩子（persona 启用 memory 才构造；钩子集合随 persona 代际冻结，18 §3.4）。
- 不做：
  - 日记写入、整理与晋升入队（P12-05）；复盘（P12-06）；kb 的 `kb:<domain>` corpus 与工具（P12-07）；向量检索（D-05）；`<memory-update>` 类通知（Q-12-2 相关，不在本单）。

## 接口草案

草案，以实现为准。

```rust
pub struct MemorySubsystem { /* store、KeywordIndex、MemoryConfig、Clock */ }
impl SubsystemHooks for MemorySubsystem {
    fn id(&self) -> &'static str { "memory" }
    /// 只在 request_index == 0 检索；其余请求返回空。块 once_per_turn = true，
    /// 由账本追加并化石化（04），子系统不直接写账本。
    fn before_request<'a>(&'a self, cx: &'a HookCx, req: &'a RequestView)
        -> BoxFuture<'a, Result<Vec<TailBlock>, HookError>>;
    /// 回合终态后：登记召回、更新强度与续期（后台车道）。
    fn after_turn<'a>(&'a self, cx: &'a HookCx, turn: &'a TurnDigest)
        -> BoxFuture<'a, Result<(), HookError>>;
    /// 压缩提交后：被逐出 Raw 进 evicted:<session> 倒排。
    fn on_evict<'a>(&'a self, cx: &'a HookCx, span: &'a EvictedSpan)
        -> BoxFuture<'a, Result<(), HookError>>;
}

/// 唯一渲染函数（11 §6.3）；正文原语言，外壳英文。
pub fn render_recalled(items: &[SelectedMemory]) -> String;
```

## 测试与守护

- **召回确定性与化石化**：同一状态连续两次 `before_request` 输出字节相同；mock 断言第 N+1 轮请求中第 N 轮的召回块逐字节保留；去掉化石化（重新渲染），红。
- **`once_per_turn`**：工具循环 5 个请求只注入一次；去掉判断，红。
- **dedup**：水位以上的同 id 同哈希召回不重复；去掉 dedup，红。
- **超时与失败**：注入慢检索 → 500 ms 后空注入 + `memory.recall_skipped{reason:"timeout"}`；去掉超时，红。
- **场所过滤**：`Subagent` / `Review` / `Job` / `Timer` 回合不召回、不登记；去掉过滤，红。
- **evicted 检索**：压缩后 `search_evicted_context` 能查到折叠原文且只覆盖本会话；返回带 `EntrySeq`；删掉 `on_evict` 写入，红。
- **限额**：单条 120 字符截断带 id（可用 `recall_memories(id=)` 取全文）、总计 ≤ 1800；越限夹具红。
- 先红后绿对照（PR 贴输出）：去掉 `once_per_turn`、去掉 dedup 各一次。
