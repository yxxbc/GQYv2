## 目标

知识库与记忆分开落地：库中只存索引（`kb_documents` / `kb_chunks` + `corpus='kb:<domain>'` 的倒排），文档本体是普通 Markdown / 文本文件；三域（`manual` 编译期嵌入只读、`user`、自定义域）；启动与每 `scan_interval_s`（默认 60）扫描，mtime / size 变化后哈希变了才重建分块与倒排；`kb_search` / `kb_read` / `kb_write` 三工具；`kb:` 作为 `StorageDomain` 在组装处注册；上传闸门只看落点路径与技能标记，不按正文关键词；`kb-index` 节在会话创建时渲染并冻结。

## 范围

- 做：
  - 表与迁移：`kb_documents(domain, path, content_hash, size, mtime, indexed_at)`、`kb_chunks(domain, path, chunk_idx, start, end)`（DDL 先补进 10 §7.6 与 11 §10.1；只增迁移）。
  - 域与目录：`manual`（内置使用手册，编译期嵌入，版本随程序，只读）、`user`（`kb/user/`）、`<自定义>`（`kb/<domain>/`，例如 `arch`、`work`）；`[kb].domains` 默认 `["manual", "user"]`。
  - 扫描（后台车道，接 P13-02）：启动一次 + 每 `scan_interval_s`；mtime / size 变化 → blake3；哈希变了才重建该文档的分块（按标题与空行切分，目标 `chunk_chars` = 800）与 `kb:<domain>` 倒排（复用 P12-03 的 `index_in_tx`）；文件被外部删除 → 下次扫描删索引行。
  - 工具：`kb_search`（`query`、`domain?`、`limit ≤ 10`；返回 `kb:<domain>/<path>#chunk` 与摘录）、`kb_read`（`path`、`offset?`、`limit?`；与 `read` 同一套分页上限）、`kb_write`（统一补丁格式，只能写可写域；`manual` 域返回英文错误）。
  - `kb:` 域：`StorageDomain` 实现（`resolve` / `read` / `list` / `apply`；`writable` 按域）；在 `gqy-daemon` 组装时注册进 `DomainTable`（07 §9.2）；按 persona 启用的域清单限定可见范围。
  - 上传闸门（沿用 v1 最终版做法）：落点路径属于 GQY 资产目录（`config/`、`personas/`、`extensions/`、`data/`）或正文带技能文件标记 → 拒绝；**不**按正文关键词拦截。
  - `kb-index` 提供者：会话创建时列出启用域与每域文档数、每域最多 `index_titles_in_system`（默认 20）个标题，交给 P11-06 的 `SystemSection::KbIndex`；会话内 kb 变化不改 system，新文档经 `kb_search` 可见；`manual` 升级后在下一压缩或新会话进入 system（11 §10.3）。
  - 配置：`[kb]` 的 `scan_interval_s` / `chunk_chars` / `index_titles_in_system` / `domains` 落进 `gqy-config`（默认值唯一来源）。
- 不做：
  - 语义 / 向量检索（D-05）；v1 kb 与 `default-kb` 的导入（P16）；TUI / Web 的 kb 浏览与上传界面（另开单）；HTTP 上传路由（必要时随 Web 阶段开单，本单落工具与域）。

## 接口草案

草案，以实现为准。

```rust
pub struct KbDomain { pub name: String, pub writable: bool, pub location: KbLocation }
pub enum KbLocation { Embedded, Directory(PathBuf) }

/// 扫描是多域一次遍历；返回重建过的文档集合（用于日志与测试断言）。
pub async fn scan_kb(kb: &Kb, domains: &[KbDomain]) -> Result<ScanReport, MemoryError>;

impl StorageDomain for KbDomainProvider { /* prefix() == "kb:"；按域读写隔离 */ }

/// system 节内容：启用域 + 文档数 + 每域最多 N 个标题；无内容返回 None（整节省略）。
pub fn kb_index_section(kb: &Kb, enabled: &[String], max_titles: usize) -> Option<String>;
```

## 实施步骤

1. 两表迁移与域目录解析（先写「manual 只读」用例）。
2. 扫描与哈希判定；分块与 `kb:<domain>` 倒排（接 P12-03）。
3. 三工具与域前缀路径核对（`read` / `glob` / `grep` / `apply_patch` 走同一机制）。
4. `StorageDomain` 注册与可见性限定；上传闸门。
5. `kb-index` 提供者接 P11-06 接缝；会话创建冻结用例。
6. `cargo xtask check`、`cargo test -p gqy-memory`；提交：`feat(memory): 知识库与 kb 域`。

## 测试与守护

- **扫描可见**：外部修改文件后 60 s 内可被 `kb_search` 检到；把哈希判定去掉（每次重建），白盒断言红或日志次数异常。
- **`manual` 只读**：`kb_write` 到 `manual` 域 → 英文错误；去掉检查，红。
- **system 冻结**：kb 变化后，已有会话的 `kb-index` 字节不变（P11-06 门禁联测）；把索引改为每回合刷新，红。
- **删除与回退**：文件被外部删除 → 索引行被删、`kb_read` 返回 not found。
- **闸门**：落点路径命中资产目录 / 技能标记 → 拒绝；正文里出现“可疑词”不被拦（v1 误伤的回归）。
- **域隔离**：未启用域与不可写域的读写被拒；`kb:` 前缀不经文件系统路径守卫（07 §9.1）。
- 先红后绿对照（PR 贴输出）：去掉哈希判定、把闸门改回关键词匹配各一次。

## 风险与回退

- **大文件与扫描成本**：分块与哈希在后台车道；单文件上限与跳过二进制文件的规则随实现写进 PR，并在 11 §10.1 补一句（先改设计再改代码）。
- **`manual` 的更新节奏**：只经“下一压缩 / 新会话”，与 11 §10.3 一致；不在会话中热更新 system。
- **回退**：停注册扫描作业与 `kb:` 域即可；两表与 `kb/` 目录是追加数据，不影响记忆功能。
