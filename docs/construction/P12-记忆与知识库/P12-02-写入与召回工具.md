## 目标

记忆写入与读取成为模型可用的工具：`remember`、`recall_memories`、`forget_memory` 在 persona 启用 `memory` 子系统时才进工具面；写入是单写作业（代数比对 → 插行 → 标签 / 主题子表），不一致就整批拒绝；`correction` 必须带 `reason`；`forget_memory` 只标记不删除，且只能作用于当前 scope 可见的记忆。做完之后：模型无法通过任何参数放宽可见性；错误一律英文并写清期望值与实际值；stub 摘要 ≤ 60 字符。

## 范围

- 做：
  - 三工具（`Tool` trait）：`remember`（`content`、`kind: fact|correction`、`reason?`、`importance?`、`visibility?`、`tags?`；`effect_class = Writes`）、`recall_memories`（`query?`、`id?`、`limit ≤ 10`、`include_forgotten?`；`ReadOnly`）、`forget_memory`（`id`、`reason`；`Writes`）。
  - 参数收口（07 §7.2 已有机制）：`correction` 缺 `reason` → 英文错误；`importance` 默认 3、范围 1–5；`correction` 固定 5；正文与标签长度走上限机制，不新造配置键。
  - 写入裁决接 P12-01：可见性只可能被收窄；Owner 私有场所显式要 `public` 时允许放宽并记审计（Q-11-4 推荐：Owner 自动放行只记审计）。
  - 单写作业：`SELECT generation FROM memory_scopes`（回合开始时读到的代数随调用携带）→ 不等 → 拒写并返回英文说明（拒绝事件在 P12-08 接上）；成功 → 插行 + `memory_tags` / `memory_subjects`。倒排更新不另开事务：P12-03 在同一写作业内追加（接缝先留出）。
  - `recall_memories`：`id` 路径返回全文（分页上限照 07）；`query` 路径在 P12-03 接检索器（本单定参数与错误形状，`query` 未接时段返回明确英文错误）；`include_forgotten` 只在 Owner 场所有效，非 Owner 按收窄处理并在结果中说明。
  - `forget_memory`：`status = forgotten`（不删除）；不可见或不存在 → 同一条英文错误（不泄露存在性）。
  - 注册与门禁：`gqy-daemon` 组装处注册 `ToolSource`，persona 启用集过滤；形状夹具刷新（含 stub 摘要的英文与长度断言）。
- 不做：
  - 检索实现与倒排维护（P12-03）；`search_evicted_context`（P12-04）；kb 工具（P12-07）；日记写入与整理（P12-05）；reset 与代数变更（P12-08）；审批界面（P07 已有）。

## 接口草案

草案，以实现为准。

```rust
pub struct RememberArgs { pub content: String, pub kind: RememberKind,
    pub reason: Option<String>, pub importance: Option<u8>,
    pub visibility: Option<Visibility>, pub tags: Vec<String> }

/// 错误示例：`"correction requires a reason: kind=correction, reason=missing"`
pub async fn remember(ctx: &ToolContext, args: RememberArgs) -> Result<String, ToolError>;
pub async fn recall_memories(ctx: &ToolContext, q: RecallQuery) -> Result<String, ToolError>;
pub async fn forget_memory(ctx: &ToolContext, id: MemoryId, reason: String) -> Result<String, ToolError>;
```

## 实施步骤

1. 三工具骨架与参数收口（先写「correction 缺 reason」会红用例）。
2. 写入作业 + 代数比对 + 子表写入。
3. `recall_memories` 的 `id` 路径与 `include_forgotten` 收窄。
4. `ToolSource` 注册与启用集过滤；形状夹具刷新。
5. `cargo xtask check`、`cargo test -p gqy-memory`；提交：`feat(memory): 写入与召回工具`。

## 测试与守护

- **可见性收窄**：非 Owner 场所模型传 `visibility="public"` → 落库为收窄值（去掉收窄，红）。
- **`correction` 约束**：缺 `reason` → 错误含期望值与实际值；`importance` 越界 → 错误列出范围。
- **代数守卫**：回合开始后（模拟另一入口 reset 使代数 +1）调用 `remember` → 写入被拒、返回英文说明；去掉比对，红。
- **存在性不泄露**：`forget_memory` 对不可见 id 与不存在 id 返回同一条错误。
- **门禁**：stub 摘要 ≤ 60 字符且全英文；形状夹具比对；persona 不启用 memory 时工具不出现在面里（去掉过滤，红）。
- **写队列满**：`StoreBusy` → 工具失败并给可读错误，不静默丢写。
- 先红后绿对照（PR 贴输出）：去掉可见性收窄、去掉代数比对各一次。
