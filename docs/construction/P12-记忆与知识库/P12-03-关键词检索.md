## 目标

关键词检索成为可替换组件：`Retriever` trait + `KeywordRetriever`（jieba-rs 搜索模式切词、中英停用词、FST 前缀与编辑距离 1 扩展、倒排候选、BM25(k1=1.2, b=0.75)、每路前 50）；RRF(k=60) 融合走通用路径（接向量检索时不改流水线）；写入路径在**同一写作业**内维护 `memory_postings` / `memory_doc_stats`——“写入即可召回”；同一库状态、同一查询、同一时钟输出字节完全相同。FST 缓存可删可重建，损坏时删除重建、重建期间退化为精确词匹配。FTS5 对照基准跑一次，结论写回 11。

## 范围

- 做：
  - 分词与规范化（唯一实现）：jieba-rs 搜索模式；统一小写与全半角；中英停用词表编译期嵌入；ASCII 词按 Unicode 单词边界切分。
  - 写入侧 `index_in_tx(tx, doc)`：插入 / 删除 / 更新词项与文档长度；只索引 `status='active'` 行；`superseded` / `forgotten` 从候选中排除（与 11 §6.2 第 4 步一致）。接上 P12-02 的写作业与 P12-01 的受控更新路径。
  - 查询侧：`terms → FST 扩展（每词 ≤ 8 个）→ 倒排候选（每路前 50）→ BM25 打分`；`short_term` 候选另要求 `expires_at > now`（时间来自注入的 `Clock`）。
  - `Retriever` trait（11 §6.2）与 `KeywordRetriever` 第一真实实现 + 测试替身；`RRF(k=60)` 融合函数（通用，只含一个检索器也走该路径）。
  - FST 缓存：`cache/fst/<corpus>-<generation>.fst`；增量写入先进内存小词表，256 个新词或 10 分钟后后台重建；损坏 → 删除重建，重建期间只做精确词匹配。
  - 确定性：排序平局按 `(score desc, created_at desc, memory_id asc)`。
  - 对照基准：FTS5（trigram 分词）同数据同查询的对照（`#[ignore = "needs:bench"]`，量法与原始数据随 PR 入库；结论回写 11 §15），FTS5 不进产品路径。
  - 体积实测：jieba 词典对二进制体积的增量记录在 PR；超 8 MB 的应对（首次使用时从内嵌压缩包解压到 `cache/`）先只记录，不提前实现（Q-11-6）。
- 不做：
  - 召回流水线的装配与注入、dedup、渲染（P12-04）；`evicted:<session>` 与 `kb:<domain>` 两个 corpus 的写入方（P12-04 / P12-07；本单的检索器与索引维护对 corpus 参数化，天然可复用）；向量检索（D-05）；`recall_memories(query=)` 的工具侧接线（本单提供函数，P12-04 前的衔接由 P12-02 的临时代码路径删除，见其「风险与回退」）。

## 接口草案

草案，以实现为准。

```rust
pub trait Retriever: Send + Sync {
    fn name(&self) -> &'static str;
    async fn search(&self, q: &RecallQuery, scope: &VisibilityPredicate, limit: usize)
        -> Result<Vec<Scored<MemoryId>>, MemoryError>;
}

pub struct RecallQuery { pub terms: Vec<String>, pub corpus: Corpus, /* … */ }
pub enum Corpus { Memories, Evicted { session: SessionId }, Kb { domain: String } }

/// 同一写作业内维护倒排；写入即可召回。
pub fn index_in_tx(tx: &mut WriteTx, doc: &IndexDoc) -> Result<(), MemoryError>;

/// RRF(k = 60)；平局由调用方按确定性规则收口。
pub fn fuse(lists: &[Vec<Scored<MemoryId>>], k: u32) -> Vec<Scored<MemoryId>>;
```

## 实施步骤

## 测试与守护

- **写入即可召回**：写入一条记忆后立即查询命中；去掉写作业里的 `index_in_tx`，红。
- **中文词级匹配**：查询 `配色` 命中日记中的 `终端配色`；去掉 jieba（按空格切分），红。
- **FST 扩展**：前缀与编辑距离 1 的错别字能扩到索引真实词项（每词 ≤ 8）；去掉扩展，红。
- **确定性**：同一库状态与查询，两次 `search` 输出字节相同；构造平局并打乱规则 → 顺序断言红。
- **缓存自愈**：删掉 / 写坏 FST 缓存文件 → 重建成功；重建期间查询只做精确词匹配（不报错）。
- **过期过滤**：`expires_at <= now` 的短期日记不出现；改快照时钟 → 结果随预期变化。
- **对照基准（`#[ignore]`）**：jieba + fst 与 FTS5 同数据对照，结论与原始数据随 PR；基准不设 CI 门禁。
- 先红后绿对照（PR 贴输出）：去掉 `index_in_tx`、去掉停用词表各一次。
