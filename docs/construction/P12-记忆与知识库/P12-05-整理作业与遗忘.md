## 目标

记忆自己长出内容并走完生命周期：`after_turn` 写短期日记（`auto_diary`，从 `Channel::Raw` 取，不含化石、XML 外壳与运行时噪声）；整理器把日记提炼为 `fact` / `long_term` / `correction`（写回带代数比对，reset 后不复活）；每日衰减按半衰期更新强度，低于阈值转 `forgotten`（不删除，可显式找回）；已整理且过期的日记物理删除，未整理的过期日记不召回但保留。全部是持久化作业：退避（2 s → 300 s ×2，±20% 抖动）、重启不丢、耗尽进 `dead` 并发 `work.dead`。

## 范围

- 做：
  - 日记：`after_turn` 写 `short_term`（`expires_at = created + 14 d`；Internal 场所不写）；正文只从 `Channel::Raw` 取；`StoreBusy` → 不重试不补写、记 `warn` 与 `memory.diary_dropped` 计数。
  - 整理触发（三个来源）：未整理（`consolidated_at IS NULL`）累计 ≥ `organize_batch_threshold`（默认 14）；某条日记召回次数（`COUNT(memory_recalls)` + `imported_recall_count`）达 `promotion_recalls`（默认 3）；daemon 启动时发现积压。
  - 工作项：`work_items.kind = 'memory.organize'`、`dedupe_key = 'memory.organize:<persona_id>'`（同一 persona 同时只有一个待办）；接入 P13-02 的领取 / 租约 / 重启恢复。
  - 执行：每次最多 4 批、每批 ≤ 20 条；每批一次辅助请求（角色 `organizer`、档位 standard、独立缓存、超时 120 s）；输出必须是符合 JSON Schema 的 `{facts, long_term, corrections}`；解析失败按失败处理，原始输出存 blob 取证。
  - 写回（一个写作业）：第一句 `SELECT generation FROM memory_scopes WHERE persona_id = ?`，与作业携带的代数不等 → 整批放弃、作业标记成功（无事可做）、记 `stale_generation`（不重试）；相等 → 插新行（`written_generation`）、写 `memory_sources` 关联、给来源日记设 `consolidated_at`。
  - 退避与终态：`next_run_at = now + min(300 s, 2 s × 2^attempt) × jitter(0.8–1.2)`；`max_attempts = 10` → `dead` + `work.dead` 事件 + doctor 列出；成功后 `attempt` 清零。
  - 衰减与遗忘（`memory.decay`，每日）：`strength = strength × 0.5^(Δt / half_life)`（默认 7 天）、更新 `last_decay_at`；`strength < 0.15` → `forgotten`；显式找回（`recall_memories(include_forgotten=true)` 后的“找回”动作）把强度重置 0.5、状态回 `active`。
  - 保留：已整理且过期的 `short_term` 由每日清理物理删除（来源原文仍在账本）；配置键照 11 §11 全表落进 `gqy-config` 的 `[memory]`（默认值唯一来源）。
- 不做：
  - 复盘与 `session_reviews`（P12-06）；reset 命令与代数变更（P12-08；本单的写回只**读取并比对**代数）；kb（P12-07）；向量（D-05）；`organizer` 输出质量的提示词调优（用 11 §7 的 schema，不在此单发明）。

## 测试与守护

- **代数守护**：作业读到代数 0 → 执行 reset（代数 1）→ 写回，断言无新行、记 `stale_generation`；去掉代数比对，红（v1 “清完又复活”的回归）。
- **退避**：mock 连续失败，`next_run_at` 序列符合 2、4、8…300 s（容许抖动区间）；第 10 次失败进 `dead` 并发 `work.dead`。
- **重启不丢**：执行中 kill daemon → 重启后被重新领取并完成，结果不重复（`(persona_id, source_key)` 唯一约束）。
- **遗忘数学**：时钟快进 7 天 → 强度减半；继续到阈值以下 → `forgotten`；显式找回 → 0.5 / `active`。
- **日记降级**：写队列满 → 不写、`warn` + `memory.diary_dropped` 计数；以后补写的行为不存在。
- **保留边界**：已整理过期日记被删；未整理过期日记保留且不参与自动召回。
- 先红后绿对照（PR 贴输出）：去掉代数比对、去掉 Internal 过滤各一次。
