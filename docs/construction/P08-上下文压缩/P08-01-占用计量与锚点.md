## 目标

占用计量成为可解释的值：本纪元锚点 + 锚点后估算 × 校准系数；四档水位（提示 0.5 / 触发 0.8 / 强制 0.9 / 发送前硬检查）在 `Stage::Preflight` 与 `Stage::InLoop` 两个检查点给出确定答案。做完之后：每回合能打印 `window/anchor/total/source/calibration` 与三条线的绝对余量；估算随真实用量收敛；`context.notice` 每会话发一次。

## 范围

- 做：
  - `Occupancy`/`Anchor`/`OccupancySource` 值类型照 §4.1；估算器为 `gqy-core` 纯函数：ASCII 约 4 字符/token、CJK 约 1.5、其余按 UTF-8 字节/3、工具 schema 与 JSON 结构按字节/3.5（Q-05-1 按推荐，零数据依赖）。
  - 锚点：本纪元最近一次成功主链请求的 `input_total + output`（06 §14 归一化口径，含缓存命中部分）；`malformed` 用量不作锚点；纪元切换（压缩、撤销、换模型）后旧锚点**结构性作废**，改全量估算直到新纪元首个真实用量。
  - 校准：真实增量 / 估算增量的指数滑动平均，初值 1.0，夹在 [0.5, 2.0]；固定序列断言收敛与夹取。
  - 水位与检查点（§4.2）：回合 `Planning` 开局与工具循环每次 `Planning` 各查一次；`Compactor::needs(ctx, stage)` 的水位部分接真（四道闸的跳过归 P08-05）；发送前硬检查 `total + max_output_tokens > window` 与强制档同判（消费归 P08-07）。
  - `context.notice`：一次/会话（`notice_sent` 进会话状态）、`context.notice_enabled` 可关闭。
  - 配置：`context.notice_ratio` / `trigger_ratio` / `force_ratio` / `notice_enabled` / `tail_tokens`（`auto`）/ `tail_min_turns` 默认值；`Config::validate` 强制偏序 `notice < trigger < force < 1.0`，违反即配置校验失败。
  - 状态持久化：`OccupancyState`（锚点、校准、`notice_sent`）随会话持久化——承位列先按复核清单回填 10。
- 不做：
  - 四道闸的判定与事件（P08-05）、压缩本体与切点（P08-02）、溢出识别（P08-07）。
  - 尾巴预算的使用（`tail_*` 的消费在 P08-02）；`/usage` 界面（TUI / Web 在 P09/P10）。

## 接口草案

草案，以实现为准。

```rust
// gqy-core/src/context/tokens.rs（纯函数；Q-05-1 按推荐：启发式 + 锚点校准）
pub fn estimate_tokens(text: &str, kind: EstimateKind) -> u32;   // Text | ToolSchema | Json
pub struct Occupancy { pub window: u32, pub anchor: Option<Anchor>, pub estimated_since_anchor: u32,
    pub calibration: f32, pub total: u32, pub source: OccupancySource }
pub struct Anchor { pub request_seq: u32, pub tokens: u32 /* input_total + output */, pub epoch: u32 }
pub enum OccupancySource { Anchor, Estimated }

// gqy-engine/src/meter.rs
impl Meter {
    pub fn needs_compaction(&self, stage: Stage, max_output_tokens: u32) -> WatermarkDecision;
    pub fn on_usage(&mut self, u: &NormalizedUsage, epoch: u32);   // 锚点与校准更新；malformed 跳过
    pub fn on_epoch_change(&mut self, reason: ColdStartReason);    // 旧锚点作废
}
pub enum WatermarkDecision { None, Notice, Trigger, Force, SendCheck }
```

## 实施步骤

1. 估算器与向量测试（先写 ASCII / CJK / 混合会红样例）。
2. `Occupancy` 与锚点生命周期（纪元作废、`malformed` 不计）。
3. 校准 EMA 与固定序列测试。
4. 水位判定 + `needs` 接线 + `context.notice`；配置默认值与偏序校验。
5. 会话状态持久化（先回填 10 §7.2 的承位）。
6. `cargo xtask check --fast`、`cargo test -p gqy-core -p gqy-engine -p gqy-config`；提交：`feat(context): 占用计量与锚点`。

## 测试与守护

- **估算器**：三组固定文本对照 §4.1 系数；单调性；空文本 0。
- **锚点**：成功请求后 `source == Anchor` 且 `total` 用真实值；伪造 `malformed` 用量 → 不作锚点（去掉该跳过，测试红）；纪元切换后旧锚点失效（去掉作废逻辑，测试红）。
- **校准**：真实 / 估算 2× 偏差序列 → 系数向 2.0 收敛且夹在界内；去掉夹取边界红。
- **水位**：0.49 / 0.5 / 0.79 / 0.8 / 0.89 / 0.9 六边界逐点断言；去掉任一档，对应行红。
- **发送前硬检查**：`total + max_output = window + 1` → 与强制档同判。
- **notice**：一次会话只发一次；关闭配置后不发；恢复会话不重复发。
- 先红后绿对照（PR 贴输出）：把锚点去掉纪元号、把校准固定为 1.0 各一次。
