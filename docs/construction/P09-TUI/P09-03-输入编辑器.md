## 目标

`Editor` 与 `EditorLayout::compute` 成为输入的唯一实现：绘制、`LayoutModel.input_rows`、点击反查三者共享同一份换行结果；字素级编辑、注入式键位表、bracketed paste 折叠、会话内历史与提交路径就位。做完之后，v1 #10（换行后点击错位）有结构性回归守护，中文与 emoji 输入不 panic，粘贴大段文本不会打爆输入框。

## 范围

- 做：
  - `Editor { buffer, caret, selection, history, pastes }`（§6.1；`caret` 为字节偏移且总在字素边界）。
  - `EditorLayout::compute(buffer, width) -> { rows, caret_pos }`：绘制、`input_rows`、点击反查三处共用（修 v1 #10）。
  - 输入高度：1 行起，最多 `min(10, 终端高度 / 3)` 行，超出时编辑器内部滚动；光标始终可见（与 `LayoutModel.cursor` 一致）。
  - 键位默认（§6.1）：Enter 发送；Shift+Enter / Alt+Enter 换行（终端不区分时用 Ctrl+J）；↑↓ 在首 / 末行时翻历史；Ctrl+C 三态（有运行取消、无运行清空、连按两次退出）；Esc 关闭浮层；Tab 补全（接 P09-04）；Ctrl+R 搜索历史。键位以注入的映射表实现，配置覆盖归 P11。
  - 粘贴：启用 bracketed paste；超过 2000 字符或 50 行的粘贴折叠为 `[pasted N lines]` 占位块，发送时展开为原文。
  - 历史：会话内内存 ring（Q-14-4 拍板前不写本地文件、不落 daemon）。
  - 提交：空输入 / 纯空白不发送；带 `client_request_id`；经 effects 调 `gqy-client` 的提交接口。
- 不做：
  - 命令补全与分发（P09-04）、抽屉内单行输入（P09-05）、多行富文本与 IME 组合优化（先如实手检）、daemon 侧历史路由（Q-14-4）。

## 接口草案

草案，以实现为准。

```rust
// apps/tui/src/editor/mod.rs（照 14 §6.1）
pub struct Editor { pub buffer: String, pub caret: usize, pub selection: Option<Range<usize>>,
                    pub history: History, pub pastes: Vec<PasteBlock> }
pub struct EditorLayout { pub rows: Vec<RowSpan>, pub caret_pos: Position }
impl EditorLayout { pub fn compute(buffer: &str, width: u16) -> EditorLayout; }

pub fn caret_index_at(layout: &EditorLayout, pos: Position) -> Option<usize>;
pub fn pos_of(layout: &EditorLayout, caret_index: usize) -> Option<Position>;

pub enum EditorAction { Insert, Submit, Newline, HistoryPrev, HistoryNext, Search, Clear, Cancel, None }
pub fn on_key(editor: &mut Editor, key: KeyEvent, map: &KeyMap) -> EditorAction;   // 纯函数
```

## 测试与守护

- **命中互逆（proptest）**：随机文本与宽度，对每个字素索引 i：`caret_index_at(pos_of(i)) == i`（把布局改回“装饰宽度 + 全宽”的旧算法，测试红；14 §13，v1 #10）。
- **预留行数**：`LayoutModel.input_rows == min(rows.len(), 上限)`，与 P09-01 的接缝断言合流（两处计算一改一留，测试红）。
- **键位表驱动**：Enter / Shift+Enter / Ctrl+J / ↑↓ 首末行边界 / Ctrl+C 三态 / Ctrl+R；新增键位无分支时编译失败（穷尽匹配）。
- **粘贴**：2000 字符与 50 行两条边界；折叠 → 发送展开后与原文逐字节相同（展开少一字节，测试红）。
- **历史**：↑↓ 环的边界、Ctrl+R 搜索；断言不产生任何本地文件写（Q-14-4 口径）。
- **字素**：中英混排移动 / 删除 / Home / End 不 panic；光标永不落在字素中间（属性测试）。
- 先红后绿对照（PR 贴输出）：去掉命中反查的共享布局、去掉粘贴展开各一次。
