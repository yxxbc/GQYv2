## 目标

审批与提问成为一等界面：抽屉浮层按到达顺序排队、显示沙盒与“本会话同意”的范围、默认焦点在“拒绝”（Enter 即 `Deny`）；Ask 支持单选 / 多选 / 自由文本与多题分页；`question.answered` / `question.closed` 自动收队。做完之后，v1 没有 Question 消费者的缺口关闭，审批默认失败关闭。

## 范围

- 做：
  - 消费 `question.asked` / `answered` / `closed` / `unanswerable`：待答队列按到达序；浮层标题显示 “1/3”；`unanswerable` 只在底栏提示（12 §6.2 的非交互场所语义由服务端给事件，界面不推断）。
  - 审批卡片（08 §5.1）：工具名、`EffectClass` 用颜色区分（Exec / Writes / Network）、`ApprovalPreview`（命令行全文、编辑类 unified diff 前 200 行、路径列表）、`sandbox` 摘要（backend、写根、“network: not restricted”、unsandboxed 醒目标注）、`session_key_preview`；`choices` 无 `AllowForSession` 时不显示 `a`（Dangerous）。
  - 操作：`y` AllowOnce、`a` AllowForSession、`n` Deny、`e` Deny + 单行备注；默认焦点「拒绝」，Enter 发送 `Deny`（14 §13）；Esc 收起、F2 重开；底栏 “awaiting approval”；工具条目显示等待状态（P09-02 的 `ItemState`）。
  - Ask：单选（数字 / 方向键）、多选（空格勾选）、自由文本（`allow_free_text`）、多题分页、最后一页确认提交；`Dismiss` 语义（Ask 视为无回答、Approval 视为 Deny）。
  - 闭环：其它客户端先答 → `question.answered` 收起本地浮层；运行取消 → `closed{run_ended}` 自动消失；`closed{expired}`（启动恢复）同样收队。
- 不做：
  - 回答者权限校验与先到先得（服务端，P07-02 / P05-07 已有）、连接器文本审批（P14）、Web 抽屉（P10-05 用同一 `QuestionView` 形状重渲染）、问题历史浏览。

## 接口草案

草案，以实现为准。

```rust
// apps/tui/src/state/questions.rs
pub struct PendingQuestion { pub view: QuestionView, pub focus: Focus, pub page: usize, pub note: Option<String> }
pub enum Focus { Deny, AllowOnce, AllowForSession, FreeText }

// apps/tui/src/view/drawer.rs（纯函数，键位 → 动作）
pub enum DrawerAction { Submit(Answer), Collapse, Reopen, Note(String), PagePrev, PageNext, Noop }
pub fn drawer_key(q: &PendingQuestion, key: KeyEvent) -> DrawerAction;
pub fn to_answer(q: &PendingQuestion) -> Answer;      // Ask：分页汇总；Approval：decision + note
```

## 测试与守护

- **默认拒绝**：浮层打开后直接 Enter → 发出 `Deny`（把默认焦点改到允许，测试红；14 §13）。
- **三答**：`y` / `a` / `n` 各发出正确 `Answer` 形状；`choices` 无 `AllowForSession` 时 `a` 不可达（Dangerous 守护；改回无条件显示，测试红）。
- **备注**：`e` → `Deny` + note 文本进入请求体；note 为空时 `note: None`。
- **卡片要素**：喂入含 `sandbox` / `session_key_preview` 的 `question.asked` 夹具，逐项断言渲染（缺一即红）。
- **队列**：两个问题排队 → 标题 “1/3” 口径正确；`question.answered`（他人）→ 本地收起；`closed{run_ended}` → 消失且焦点回输入框（浮层粘住，测试红）。
- **Ask**：单选 / 多选 / 自由文本的 payload 形状；未到最后一页不提交；`Dismiss` 语义。
- **unanswerable**：底栏提示且不弹抽屉。
- **快照**：80×24 审批浮层（完整矩阵在 P09-07）。
- 先红后绿对照（PR 贴输出）：把默认焦点改成“允许一次”、把危险类别过滤删掉各一次。

## 风险与回退

- **焦点管理**：Esc 收起后键盘去哪（回输入框）；与 P09-02 的等待态对接，`ItemState` 定义冻结后不改。
- **`AllowForSession` 的显隐口径**：以 `choices` 为准，不在前端按 effect 自行推断持久授权（08 是唯一判定处）。
- **回退**：`drawer` 相关模块可整体 revert；回退后审批在 TUI 不可答（只剩取消路径），不降级为自动允许——与 08 的失败关闭一致。
