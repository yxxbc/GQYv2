## 目标

`apps/tui` 完成结构重组：主循环改为 `Msg → update → (State, Vec<Effect>) → draw`；布局由 `LayoutModel::compute` 每帧恰好算一次，绘制、光标、命中、预留行数读同一份几何；Lobby / Conversation / Inline 三模式与「终端太小」降级就位；断线、`resync`、`daemon.stopping` 有状态条显示。做完之后，v1 #1（底栏闪跳）与 #10（换行后点击错位）在结构上不可复现，xtask 扫描它们赖以发生的“单行覆写”。

## 范围

- 做：
  - 目录与单向数据流照 14 §3：`state/`（纯数据）、`update/`（纯函数 `(State, Msg) -> (State, Vec<Effect>)`）、`layout/`（唯一几何来源）、`view/`（只读）、`effects/`（副作用执行）；`main.rs` 只做参数与启动。
  - `LayoutModel`（§4.1 字段照抄：`area`、`mode`、`header`、`transcript`、`transcript_window`、`input_box`、`input_text`、`input_rows`、`footer`、`overlays`、`images`、`cursor`、`hit`）与 `LayoutCaches`；装饰宽度等常量只在 `layout/metrics.rs` 定义。
  - 三种模式与最小尺寸（§4.2）：Lobby / Conversation / Inline；小于最小尺寸只画一行 “terminal too small: need ≥40×12, got W×H”。
  - `HitMap`：区域 → 命中目标；鼠标事件经 `layout.hit.resolve(pos)`。
  - 状态条：disconnected — retrying in Ns（指数退避 0.5 s → 8 s）、`stream.resync_required` 后保留锚点重建、`daemon.stopping` 停止发送。
  - `Destination::Transcript | Toast | Overlay`（§4.1 规则 4）与 `fit(&self, avail) -> Fit` 的公共返回类型（§4.1 规则 5）。
  - xtask 静态规则：扫描 `apps/tui/src` 中 `crossterm::cursor::MoveTo`、`execute!`、`queue!`、`print!`、`println!`（白名单：`image/` 与 `app.rs` 的终端初始化）+ 违规样例测试（19 §6.1 第 5 项）。

  - 转录条目与虚拟化（P09-02）、编辑器（P09-03）、命令（P09-04）、审批浮层内容（P09-05）、会话 / 作业面板（P09-06）；主题与 `tui.*` 配置读取（P09-07 / P11-01）、图片协议探测与绘制（见 README 遗留）。

## 接口草案

草案，以实现为准。

```rust
// apps/tui/src/layout/mod.rs（照 14 §4.1）
pub struct LayoutModel { /* area, mode, header, transcript, transcript_window, input_box,
                           input_text, input_rows, footer, overlays, images, cursor, hit */ }
pub enum LayoutMode { Lobby, Conversation, Inline }
pub enum Destination { Transcript, Toast, Overlay }
pub enum Fit { Full, Reduced(u8), Placeholder }

impl LayoutModel {
    pub fn compute(area: Rect, state: &UiState, caches: &mut LayoutCaches) -> LayoutModel;
}

// apps/tui/src/update/mod.rs（纯函数，无 IO；可在单测里直接驱动）
pub enum Msg { Key(KeyEvent), Mouse(MouseEvent), Resize(Rect), Event(Event), Tick(FrameTick), Resp(EffectResult) }
pub fn update(state: AppState, msg: Msg) -> (AppState, Vec<Effect>);
```

## 测试与守护

- **布局是纯函数**：同一 `(area, state)` 两次 `compute` 结果相同；属性测试断言所有矩形在 `area` 内、`footer.height == 1`、非浮层矩形互不重叠（去掉任意一条，对应用例红）。
- **预留行数接缝**：`input_rows` 与编辑器 `EditorLayout::compute(buffer, input_text.width)` 的行数一致（夹到上限）——编辑器尚未落地前用测试替身验证；P09-03 换真实现后升级为 v1 #10 回归（14 §13）。
- **底栏稳定性（v1 #1）**：模拟“空会话 → 提交 → 转轮 tick × 20 → 回合结束”，断言每帧 `footer` 矩形完全相同（把底栏改回按窄框边距计算，测试红）。
- **单一路径扫描**：`xtask` 违规样例里放一个 `println!` 与一个 `MoveTo`，断言报红；去掉扫描规则后样例测试红。
- **最小尺寸**：40×12 以下任意尺寸不 panic，画单行提示；恢复到 ≥40×12 后布局正常。
- **断线与续传**：`ScriptedClient` 断流 → 状态条出现计数退避；重连携带 `Last-Event-ID = as_of_seq`（13 §6.4）；`resync_required` 后锚点保留（锚点条目仍存在时）。
- **去向类型**：`Toast` 只接受可丢失状态；命令回执的去向断言留给 P09-04，此处断言类型层不允许“按长度推断去向”。
- 先红后绿对照（PR 贴输出）：把底栏矩形改成不读模型、把扫描规则删掉各一次。
