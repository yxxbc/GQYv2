## 目标

命令只有一张表：客户端命令表与服务端命令表（`GET /commands`）合并成 `CommandTable`；补全、`/help`、分发与命令目录同源；客户端命令用枚举穷尽匹配；服务端命令结果按 `CommandOutcome` 去向渲染（`notice` 进转录，`opens` 打开浮层，先做用量浮层）。做完之后，新增一条命令 = 一行表 + 一个分支（漏分支编译失败），命令回执不再走会过期的通知条。

## 范围

- 做：
  - 客户端命令（首版）：`/quit`、`/clear-screen`、`/theme`、`/web`、`/help`；`/sessions`、`/jobs` 随 P09-06 登记（同一张表）。
  - `/theme` 只切会话内主题（持久化归 P11 的 `tui.theme`）；`/web` 经 `gqy-client` 请求一次性配对码并打印 `http://127.0.0.1:<port>/#pair=<code>`（13 §8.3；`gqy-client` 缺接口则先补）。
  - 合并 `CommandTable`：名称与别名冲突时启动报错（测试守护）。
  - 补全：按前缀过滤（客户端 + 服务端），Tab 触发候选浮层（占位读 `layout.overlays`）。
  - `/help`：遍历同一张表输出，文案走 i18n 键（12 §9）。
  - 服务端命令：`POST /sessions/{id}/commands`；`notice` → `Destination::Transcript`；`opens` → 打开对应浮层；用量浮层（`GET /usage` 四桶 + `usage.updated` 会话累计）作为 `opens` 的第一个消费者（修 v1 #3）。
  - 去向显式（§4.1 规则 4）：回执默认 Transcript；Toast 只用于可丢失状态且时长有来源（复核清单第 5 条）。
- 不做：
  - Web 侧命令 UI（P10-05）、`/config` 菜单（P11-01）、`/compact` 等命令的引擎语义（P08 已实现，本单只做入口与渲染）、键位配置覆盖（P11）。

## 接口草案

草案，以实现为准。

```rust
// gqy-protocol 的现状以 P05-01 为准；下面是 14 §6.2 的形状，供核对
pub struct CommandSpec { pub name: String, pub aliases: Vec<String>, pub args: ArgSpec,
    pub summary_key: String, pub scope: CommandScope, pub availability: Availability }

pub enum ClientCommand { Quit, ClearScreen, Theme, Web, Help }   // 穷尽匹配；P09-06 追加
pub struct CommandTable { /* 合并后的客户端 + 服务端，构造后不可变 */ }
impl CommandTable {
    pub fn merge(client: &[ClientCommandSpec], server: Vec<CommandSpec>) -> Result<CommandTable, TableError>;
    pub fn complete(&self, prefix: &str) -> Vec<&CommandSpec>;
    pub async fn dispatch(&self, input: &str, deps: &mut Deps) -> Result<Dispatch, CommandError>;
}
```

## 实施步骤

1. 客户端表与 `merge`、冲突检测（先写同名报错的会红断言）。
2. 补全与 `/help`（纯函数 + 浮层渲染）。
3. 分发与 `ClientCommand` 穷尽匹配。
4. 服务端命令 POST 与 `CommandOutcome` 渲染；用量浮层。
5. `/web` 配对码路径；`/theme` 会话内切换。
6. `cargo xtask check --fast`、`cargo test -p gqy-tui`；提交：`feat(tui): 命令只有一张表`。

## 测试与守护

- **冲突检测**：构造同名客户端 / 服务端命令 → 启动报错并列出双方（去掉检测，测试红）。
- **表与分发一致**：遍历 `CommandTable` 断言每条命令都有处理路径（表加了、分发忘了 → 测试红）；`ClientCommand` 穷尽匹配由编译器保证。
- **去向（v1 #2）**：命令回执在暂停时钟推进 5 秒后仍在转录；把回执改回通知条，测试红。
- **`/usage` 打开浮层（v1 #3）**：执行后浮层打开且四桶数值来自响应；改成只发 notice，测试红。
- **补全纯函数**：空输入 / 前缀 / 别名 / 大小写；过滤结果排序稳定。
- **服务端命令联测**：mock 下断言 POST 的名称与参数、`notice` 文本进转录。
- **`/web`**：mock 配对码接口 → 输出 URL 形状与一次性语义；真端口步骤标「需用户环境」。
- 先红后绿对照（PR 贴输出）：把回执改成通知条、把冲突检测去掉各一次。
