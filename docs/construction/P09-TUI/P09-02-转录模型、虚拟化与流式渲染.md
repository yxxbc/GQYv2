## 目标

转录成为独立模型：条目、换行缓存、高度索引、滚动锚点与可见窗口；流式 markdown 按块冻结；工具条目总是可展开；图片按格子占位与降级。做完之后，10k 条目会话的滚动与 resize 只重算可见窗口附近，v1 #9（工具条目点击无反应）与 #8（塞不下的素材静默消失）有回归守护，中文换行不再有按字节切的风险。

## 范围

- 做：
  - `TranscriptItem` / `ItemKey` / `ItemKind` / `ItemContent` / `ItemState` / `WrapCache`（§5.1）。
  - 条目来源两条（历史页与事件流）都经同一个 `apply_event` / `apply_entry` 归约（单一路径）。
  - `WrapCache`：宽度变化失效；字素簇换行（`unicode-width` / `unicode-segmentation`），禁止按字节切片（v1 有中文 `split_at` panic 前科）。
  - `HeightIndex`（Fenwick 树，按条目下标存高度）+ `ScrollAnchor { item, line_offset }`：第 k 行 → 条目与前缀和更新；resize 懒重算，未重算条目用估计高度、滚到那里再精确化。
  - 可见窗口 `VisibleWindow`；跟随模式（向上滚动退出、End / 滚回底恢复、“↓ N new”计数）；历史懒加载（首 200 条、距顶 50 行预取）。
  - 流式：`assistant.delta` 追加 Pending 条目；markdown 按块增量解析（已闭合块冻结、每帧只重解析最后一个未闭合块）；`assistant.message` 抵达后以服务端文本替换（丢弃本地拼接）；16 ms 帧节拍合并重画、转轮 100 ms。
  - 代码高亮：轻量（关键字 / 字符串），> 500 行先无高亮；`Highlighter` 接缝（Q-14-2 拍板后只换实现）。
  - 工具条目**总是**可展开：展开内容由参数与输出拼出，确实为空时显示 “no output”；被截断的长输出按需 `GET /sessions/{id}/entries/{seq}`（07 §8）。
  - 图片条目：高度计入换行缓存，`ImagePlacement { item, cells, source, scale }` 占布局分配的格子；`fit()` 返回 Full / Reduced / Placeholder，占位文本 `[image 800×600 png · Enter to open]`；只画完全可见的图片（否则画占位框）；blob 拉取 + 64 MiB LRU。
- 不做：
  - 审批与提问浮层（P09-05）、会话与作业面板（P09-06）、图片协议探测与绘制（按 Q-14-1 结论另开单）、高亮库替换（Q-14-2）。

## 接口草案

草案，以实现为准。

```rust
// 照 14 §5.1 / §5.3
pub struct TranscriptItem { pub key: ItemKey, pub kind: ItemKind, pub content: ItemContent,
    pub expandable: Option<ExpandSpec>, pub state: ItemState, pub wrap: WrapCache }
pub struct HeightIndex { /* Fenwick：条目下标 → 行数 */ }
pub struct ScrollAnchor { pub item: ItemKey, pub line_offset: u32 }
pub struct VisibleWindow { pub first: usize, pub first_line: u32, pub last: usize }

pub fn apply_entry(t: &mut Transcript, e: &EntryProjection) -> Applied;
pub fn apply_event(t: &mut Transcript, ev: &Event) -> Applied;   // 与历史页同一路径
pub fn wrap(text: &str, width: u16) -> Arc<[Line]>;               // 字素簇；禁字节切片
```

## 测试与守护

- **归约单一路径**：`crates/gqy-protocol/tests/fixtures/streams/*.jsonl` 驱动 `apply_event`，最终视图与期望 JSON 相同（14 §13）；同一序列走 `apply_entry` 与 `apply_event` 得到逐条目相同结果（把两条来源拆成第二份逻辑，测试红）。
- **换行**：中文 / emoji / 组合字素 / 零宽字符不 panic，宽度与 `unicode-width` 一致（改回按字节切片，测试红）。
- **虚拟化**：10k 条目滚动与 resize 只重算可见窗口附近（以「重算条目计数」断言，不看耗时；改成全量重算，测试红）。
- **锚点**：resize / 历史页插入 / 条目展开后，锚点条目仍在视口同一行偏移（改回绝对行号锚定，测试红）。
- **跟随**：向上滚动退出跟随、End 恢复、“↓ N new”计数正确。
- **工具条目可展开（v1 #9）**：对所有内置工具的 `tool.finished` 夹具断言 `expandable.is_some()`；空输出展开区是 “no output”；按需回取的长输出与全文一致。
- **降级（v1 #8）**：吉祥物与图片在所有测试尺寸下 `fit()` 不返回「什么都不画」，至少 Placeholder 一行。
- **快照**：80×24 的流式中帧与含展开条目的帧（完整矩阵在 P09-07）。
- 先红后绿对照（PR 贴输出）：把 delta 校准改成“只信本地拼接”、把展开区空内容改成静默返回各一次。
