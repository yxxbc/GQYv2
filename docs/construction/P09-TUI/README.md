## 阶段目标

（与施工图 `plan-data` 同文）单渲染路径布局、转录虚拟化、输入框、命令表、审批/提问界面、会话与任务面板。做完之后：

- 每一帧由 `LayoutModel::compute` 一次性算出全部几何；绘制、光标、鼠标命中、预留行数与编辑器换行读同一份结果（14 §4，修 v1 #1 / #10）；
- 10 万行会话的滚动与流式输出每帧只处理可见窗口；`resize`、历史页插入与条目展开都不改变滚动锚点（14 §5.3）；
- 审批与提问是一等界面：默认拒绝、显示沙盒与“本会话同意”的范围、多问题排队、`question.closed` 自动收队（14 §7，补上 v1 没有 Question 消费者的缺口）；
- 命令只有一张表：补全、`/help`、分发与 `GET /commands` 同源；`CommandOutcome` 的去向显式（回执进转录，`opens` 打开浮层；修 v1 #2 / #3）；
- 会话切换器、作业面板与子代理只读视图复用同一套转录组件；切换会话不打断在跑的回合（14 §8）；
- 14 §13 的守护全部进 CI：TestBackend 快照（40×12 / 80×24 / 120×40 / 200×60）、布局不变量与命中互逆属性测试、底栏稳定性、单一渲染路径扫描、工具条目可展开、降级不消失。
