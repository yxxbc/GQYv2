## 目标

用量从“供应商口径”变成一个口径：四桶互斥的 `NormalizedUsage`（四种方言的映射与交叉校验）、`Estimated` 兜底、成本计算（价格表存在时），并写进 **主库三张表 + 一行 `gqy::usage` 日志 + 一行 `prompt_cache_accounting` 日志**（同一事实、同一写作业）。做完之后，19 §3.3 的账在 P03 的 `prefix_hash` 接上后即为最终形态。

## 范围

- 做：
  - `usage.rs`：`normalize(raw: &RawUsage, dialect: UsageDialect, profile) -> NormalizedUsage`，映射表照 06 §14.2（openai-chat 的 OpenAI/DeepSeek 两套、responses、anthropic）；守恒校验照 §14.3：`cache_read + cache_write > input_total` → `malformed = true` 并**保留原始值**（不修正）；DeepSeek 的 `prompt_tokens` 与 `hit + miss` 交叉校验；流中无用量 → `Reported = Estimated`（本地估算以入参注入，P08 前为 `None` 时按 0 并标 `Estimated`，字段照旧写全）。
  - 成本：`cost(raw: &NormalizedUsage, price: &PriceTable) -> Option<Cost>`（`input_uncached × p_in + cache_read × p_read + cache_write × p_write + output × p_out`；不推测、不四舍五入到分，存 micros + currency）。
  - 迁移 `0002_usage.sql`：`llm_requests`、`usage_records`、`usage_daily`（列照 10 §7.5 逐列；`STRICT`、外键、与 10 §8 规则一致）；`CHECKSUMS` 登记。
  - `RequestRepo`（`gqy-store`）：一个写作业里插 `llm_requests` + `usage_records`（+ 当日 `usage_daily` 的增量 upsert——汇总口径照 10 §9.3，作业在 P13-02，这里只写增量以便真机可用）；按列名读的读接口。
  - 日志行：`gqy::usage`（19 §3.3 的完整字段表；`prefix_hash`/`prefix_bytes`/`prev_extends`/`expected_read_floor`/`miss_suspect` 来自 04 §14 与 `RequestRecord`，本单以“记录 + 可选上下文结构”写入，链上字段由 P03/P04 填值）与 `prompt_cache_accounting`（04 §14 的 key=value 形式）。
- 不做：
  - `prefix_hash` 的计算与 `prev_prefix_extends` 的真实判定（P03-05；本单接口与测试用夹具值）。
  - `usage_daily` 的汇总作业与保留清理（P13-02）；`events` 里的 `request.finished` 事件（P04-06；三处一致的完整版在 P05 起）。
  - 真机价格数据（用户配置；模板不附价格，06 §16）。

## 测试与守护

- **四方言映射**：每方言一个夹具（含 `prompt_cache_hit_tokens`、`cached_tokens`、`cache_creation_input_tokens`）；`output` 含推理；`reasoning_output` 子项。
- **守恒**：`read + write > total` → `malformed=true` 且四桶保留原值（v1“漏累加 cache_read”回归：漏累加的实现必红）；DeepSeek `hit+miss ≠ prompt_tokens` 的样例按 `malformed` 处理。
- **Estimated**：无用量事件 → `Estimated`、字段写全、`estimated` 列 = 1。
- **成本**：有价格表按桶相加（一个手算夹具）；无价格表 → `None`。
- **落库**：`llm_requests` 与 `usage_records` 行数、四桶、`attempts`、`timing` 往返一致；`usage_daily` 增量正确。
- **日志行**：golden 样本逐字段断言（`miss_suspect=true/false` 两种）；`prefix_*` 为空时字段省略而不是 0。
- 先红后绿对照（PR 贴输出）：不累加 `cache_read`、把 `malformed` 当 0 修正各一次。
