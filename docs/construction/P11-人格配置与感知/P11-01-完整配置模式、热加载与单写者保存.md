## 目标

配置成为唯一事实来源并可安全热更新：一份 Rust 类型生成 JSON Schema、TS 类型与带注释默认配置三样产物（CI 无漂移）；`validate()` 集中校验并给带路径的错误；daemon 内 `ConfigService` 是唯一写者，保存走「取锁 → 读修订 → `If-Match` → `toml_edit` 应用修改 → 校验 → 原子写 → 替换 `ArcSwap` → 广播事件」。做完之后：并发保存不再互相回滚（v1 教训）、改前缀字节的配置一律不是 `NextTurn`（逐字段测试）、`GET /config` 的 secret 字段只回 `{set: true}`。

  - secret 的真实存取（P11-02；本单只做 `key_ref` 校验与明文拒绝）；persona 目录与代际（P11-03）；`[perception]` 的探测与默认值内容（P11-05）；Web 设置页（P10-06）；TUI `/config` 菜单（遗留，见 README）。

## 接口草案

草案，以实现为准。

```rust
pub enum Apply { NextTurn, NewSession, Restart }
pub struct FieldMeta { pub apply: Apply, pub bounds: Option<Bounds>, pub secret: bool }
pub struct Revision(pub String);                       // blake3(文件字节) 的 hex

impl Config { pub fn validate(&self) -> Result<(), Vec<ConfigError>>; }

pub struct ConfigService { /* ArcSwap<Config> + revision + 单写者 */ }
impl ConfigService {
    /// `if_match` 与当前修订不一致 → `ConfigConflict`（HTTP 409）；成功 → 新修订并广播 `config.changed`。
    pub async fn patch(&self, ops: &JsonMergePatch, if_match: &Revision) -> Result<Revision, ConfigError>;
    /// 2 s 轮询调用；校验失败返回 `ConfigError::Invalid` 且内存配置不变。
    pub async fn reload_external(&self) -> Result<Option<Revision>, ConfigError>;
}
```

## 测试与守护

- **默认值单一来源**：改一个 `Default` 值不重生成 → 产物比对红（去掉 `--check`，该用例红）。
- **并发保存**：两客户端同修订保存 → 一成功一 409；成功路径上 `secrets.toml` 字节不变（v1 回滚 secret 的回归；去掉 `If-Match` 比对，红）。
- **写入中断**：rename 前 kill → 原文件完好；残留 tmp 在下次启动被清理（去掉清理，红）。
- **热加载不改前缀**：遍历 `apply = NextTurn` 字段逐一改非默认值，mock 供应商断言下一轮请求仍是上一轮字节前缀延伸；把一个会改前缀的字段错标 `NextTurn`，红。
- **明文 secret 拒绝**：`api_key = "sk-…"` 校验失败并给出 `gqy secret set` 提示。
- **未知键保留**：写入未知键 → `PATCH` 后仍在文件里；doctor 列出并给编辑距离提示。
- 先红后绿对照（PR 贴输出）：去掉 `If-Match` 比对、去掉 tmp 清理各一次。

## 验收流程

```sh
cargo xtask gen --check
GQY2_HOME=$(mktemp -d) cargo run -p apps/gqy -- config defaults      # 带注释的默认配置
GQY2_HOME=$(mktemp -d) cargo run -p apps/gqy -- daemon run &
TOKEN=$(cat $GQY2_HOME/run/local.token)
curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8310/api/v1/config/schema | head -c 400
# 手检：两个终端并发 PATCH /config → 后者 409；改 [log] 级别 → 下一回合生效；
#   改监听地址 → config.changed 带 restart_required；手改文件为坏 TOML → config.invalid 且旧配置继续服务
```
