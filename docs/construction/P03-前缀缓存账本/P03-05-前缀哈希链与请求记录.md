## 目标

链真的算起来：`chain(e₀) = blake3("gqy-prefix-v1" ‖ epoch ‖ stable_hash ‖ enc(e₀))`、`chain(eᵢ) = blake3(chain(eᵢ₋₁) ‖ enc(eᵢ))`（04 §10）、`prefix_hash` 写入请求记录；自检"上一次的 `prefix_hash` 出现在本次链上"，违反时开发/测试 panic、发布记 `prefix_violation` 照常发送；`StableSection` 每纪元一条；`gqy::usage` 与 `prompt_cache_accounting` 的派生字段由本单填全。做完之后，P03-03 的占位被删除，门禁（P03-06）有了链哈希可断言。

## 范围

- 做：
  - `chain.rs` 真实现替换占位：公式照 04 §10；`stable_hash` 来自 `StableSection`；`enc(e)` 用 P03-01 的规范字节；**删除 P03-03 的占位实现**（及其测试专用标注）。
  - 请求记录落库：在 P03-03 的同一事务里写 `llm_requests`（P02-07 已建表）：`prefix_hash`、`entry_from/to`、`parent_prefix`、`wire_hash`（来自 `WireRequest`）、`surface_hash`、`profile_hash`、`epoch`、`purpose`。
  - 自检（04 §10 用途 1）：`plan` 时断言上一个请求的 `prefix_hash` 在本链上；开发构建（`cfg(debug_assertions)` 或测试）直接 panic；发布构建记 `prefix_violation` 日志（含期望与实际）并照常发送。
  - 纪元记账：`open_epoch` 的调用协议（何时开、写什么 `StableSection`、打 `context_rewrite` 行）在本单定稿；`epoch` 推导 = 该会话 `StableSection` 条目数 − 1（或从条目读回；以实现为准并写进文档）。
  - 派生字段与日志（04 §14 / 19 §3.3）：`prev_input_total`（查上一条 `llm_requests`+`usage_records`）、`expected_read_floor`（按 `cache_block_tokens` 取整）、`miss_suspect`（`noise_floor` 按缓存语义类别）、`shared_prefix_bytes`、`prev_prefix_extends`（由链延伸判定；字节层的真相归 P03-06 门禁）；两行日志在请求结束时输出。
  - 辅助链（04 §11）：`epoch = 0`、`parent_prefix = None` 的记录写入路径。
- 不做：
  - 压缩的纪元写入（05、P08）；`DeviceHandoff`（17）、`V1Import`（20）的链路；本单只认枚举、不实现来源。
  - 字节前缀门禁本身（P03-06）。

## 测试与守护

- **链向量**：首条、逐条延伸、换纪元（`stable_hash` 变）三组固定向量；改任一输入字节 → 哈希变化。
- **记录**：一次冻结后 `llm_requests` 行字段与 `FrozenRequest`/`WireRequest` 逐项一致；`parent_prefix` 链接上一条。
- **自检**：去掉一条已有条目（测试构造断链）→ 开发构建 panic；发布模式记 `prefix_violation` 且不阻断发送（用 mock 断言请求仍发出）。
- **纪元记账**：`open_epoch` 一次 → 恰好一条 `StableSection`，`context_rewrite` 行原因在枚举内；重复调用按 P03-03 定的语义（幂等或拒绝）断言。
- **派生字段**：`expected_read_floor` 取整边界（block 粒度 ±1）；`miss_suspect` 的两种噪音阈值；纪元首请求不判定。
- **辅助链**：`epoch=0`、`parent_prefix=None`。
- 先红后绿对照（PR 贴输出）：`chain` 去掉 `"gqy-prefix-v1"` 前缀、自检改成恒真各一次。

## 风险与回退

- **`epoch` 推导方式**：读 `StableSection` 数与水位行的一致性要有个断言（两处数据源一个事实）；若冲突，先查 04 §9.1 再定。
- **发布路径的 `prefix_violation`**：只记日志不阻断是设计（04 §10）；不要顺手加"拒绝服务"的行为。
- **回退**：链实现与 P03-03 的占位是单点替换，revert 回到占位即可（占位保留在 git 历史里）。
