# P03 · 前缀缓存账本

> 状态：【规划】。本阶段把铁律 1「前缀即契约」变成可执行、可检验的结构：账本条目的三通道、请求规划、化石化、工具面规范化、前缀哈希链与字节前缀门禁。

## 阶段目标

账本条目、请求规划、化石化、工具面规范化、哈希链、字节前缀门禁（与施工图 `plan-data` 同文）。做完之后：

- `gqy-ledger` 是纯逻辑 crate（不碰 IO）：从账本视图产出**确定性** `RequestPlan`，与 `gqy-provider` 的编码组合成字节契约；
- 化石化与「先落库后发送」是一个事务；重启后重新编码得到与当初相同的字节；
- `surface_hash` 与 `prefix_hash` 链式记账，请求记录写进 `llm_requests`；
- mock 上的字节前缀门禁在三种协议上跑通，且每个场景有"变异版本会红"的证据。
