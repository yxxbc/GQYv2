# P14 · 连接器与平台

> 状态：【规划】。本阶段把 16 号设计落成：连接器协议端点、连接器 SDK、不可信输入通道与平台权限、投递幂等与限流、QQ（OneBot）与 iMessage 两个连接器、聊天室与 M4 验收。daemon 不认平台，只认协议；连接器是独立进程与独立二进制；外部输入一律不可信（铁律 7）。
> 创建：AI 助手（Cline 会话），2026-09-28。改动本文件时，按根 `AGENTS.md` 规矩 7 更新这一行：写清谁改的、什么时候改的。

## 阶段目标

（与施工图 `plan-data` 同文）连接器协议端点、连接器 SDK、QQ(OneBot)、iMessage、不可信输入、聊天室、投递幂等。做完之后：

- 协议 `gqy-connector/1` 在 daemon 进程内 `gqy-gateway` 的连接器端点成立：升级前鉴权（scope `connector:<platform>`、不认回环）、hello/welcome 握手、ack 只在处理完后发、`max_inflight` 背压、同一 `(platform, account)` 新连接顶替旧连接（16 §3）；
- 连接器是独立二进制（`apps/connectors/<name>/`），共享客户端逻辑只有 `gqy-connector-sdk`（L5，只依赖 `gqy-protocol` + WS 客户端库）；`gqy connector install <name>` 生成 launchd / systemd --user 服务文件，daemon 不管理连接器生命周期（00 §5 已定）；
- 不可信输入走独立通道：正文进账本 Raw（原文），送模型走 untrusted tail 并逐字段 `safe_prompt_field` 转义；可信字段（principal 角色、场所、会话类型、平台 ID）只由代码生成放 trusted tail；权限只由配置的联系人身份判定——**只信账号 id，不信昵称**（16 §5）；
- 消息不丢、不重复发：连接器保管读水位、daemon 处理完才 ack；`connector_inbound` 去重保证重放不重复跑回合；出站幂等闸拦住重复投递；`delivery_unknown` 不自动重发（16 §7）；
- 群聊硬规则：非管理员永远拿不到宿主工具；群聊默认不开宿主工具；群场所信任上限 `Member`（16 §5.2、08 §7）；
- QQ（OneBot 正向 WS 连 NapCat）与 iMessage（Rust 读 `chat.db` + `osascript` 发）可用；聊天室（每成员一个隐藏 `room-member` 会话、追加式喂入、轮流、工具全关）成立；M4「伴侣回归」验收通过并留档。

## 遗留与发现

> 施工过程中发现的范围外问题记在这里；写单时发现、需要用户拍板的点也记在这里。

写单时的口径：

1. **结构固定**：每张单按施工总纲 §3.2 写——表头（`| 状态 | 未开始 |`、依赖、`| 设计依据 |`、`| 规模 |`、`涉及 crate / 目录`）＋ 固定九节（`## 目标`、`## 范围`、`## 改动清单`、`## 接口草案`、`## 实施步骤`、`## 测试与守护`、`## 验收流程`、`## 完成判据`、`## 风险与回退`）；表头之后加一行「草案（开工前复核）」；状态以单文件头为唯一真相源，本 README 只写链接与一句话。
2. **协议与平台解耦的红线**：daemon 内出现任何平台关键字（`qq`、`onebot`、`imessage`、`chat.db`）即视为越界；连接器是独立二进制（`apps/connectors/`），只依赖 `gqy-connector-sdk` / `gqy-protocol`，由 arch 门禁与关键字扫描守护。
3. **待定项按推荐先行**：Q-16-5（`mentions_self` 加法字段，群聊只在被 @ 或被回复时触发）、Q-16-6（群聊 owner/admin 宿主工具允许但默认关，开启后仍逐次审批，Exec 只在沙盒内）；Q-16-3（iMessage 签名与安装）为研究项，P14-06 先走 ad-hoc + 固定路径的内测路径，发布形态写回 16。
4. **边界诚实**：伪造 `sender.id` 不在防护范围（连接器本身是用户信任的组件）；平台昵称、群名、引用原文、群历史全部不可信；这些都要写进用户文档（16 §10）。
5. **Q-03-3 的落地口径**：连接器非交互场所的排队项在 `queue_restart_ttl`（默认 30 min）内重启保留，由 P14-01 验收。
6. **不在本批 7 张单内**：语音入口（`VenueKind::Voice` 登记前不得构造回合，12 §6.2）；Web / TUI 的连接器与聊天室管理界面；v1 平台数据导入（P16 / P20）；连接器协议的独立中继进程（00 §5：以后可加，不改连接器）；`private_initiative`（主动发起）。
