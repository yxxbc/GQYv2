## 阶段目标

（与施工图 `plan-data` 同文）Tool trait、注册表、参数收口、文件/编辑/搜索/命令/PTY 工具、stub 与 load_tools、形状夹具。做完之后：

- 新增一个内置工具 = 一个文件 + `BUILTINS` 一行（07 §1）；
- 工具面在会话创建时编译并冻结，字节只经 P03-04 的规范化路径；重启从冻结字节恢复，与当前注册表重编比对只记 `surface_drift`，不改字节；
- 模型给的参数只在 `Dispatcher::prepare` 一处收口：还原、记录 `Coercion`、原始字节留给取证；错误写「期望 / 实际」；
- 输出写入期一次性截断（05 §10），全文进 blob，`read_output` 可回取；长命令软超时转作业、不丢回合；
- 工具循环在引擎里跑通「读、写、跑命令、转作业」：分组并发、屏障、按序落账、失败不连坐、`yes` 不吃内存；
- 六个代表性工具面进形状夹具门禁（19 §6.1 第 8 项）与「模型可见文本英文」门禁（第 13 项）。

- 工具循环接进引擎（`ToolCycle` 不再是测试替身）；mock 长会话里「多个工具调用 + 并行组 + 屏障 + 截断 + read_output 回取」的落账顺序与配对完整可断言；
