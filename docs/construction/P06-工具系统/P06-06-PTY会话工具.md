## 目标

四个 PTY 工具：`pty_open`（默认 120×40）、`pty_send`（文本或命名按键）、`pty_read`（等待输出静默后返回**屏幕快照**，不是原始转义序列）、`pty_close`。做完之后，模型能驱动 REPL 类交互程序而不把终端转义序列灌进上下文；每会话 ≤ 4 个、空闲 30 min 自动关闭、关闭按 SIGHUP → 2 s → SIGKILL。

## 范围

- 做：
  - `pty_registry.rs`：会话级注册表（≤ 4 个；空闲 30 min 关闭；会话卸载时全部关闭）。**注入点**：07 §3.3 的 `ToolContext` 现行草案没有会话级服务句柄——开工前先把该字段写进设计，再实现。
  - `gqy-sys`：PTY 原语（openpty、窗口尺寸、信号）与 `HostCap::Pty` 探测；缺失时 `pty_*` 不编译进工具面（07 §5.1 第 4 步）。
  - `screen.rs`：终端仿真（vt100 一类 crate）渲染快照；`pty_read` 的 `wait_ms ≤ 10,000` 静默判定用注入的 Clock。
  - `pty_send`：文本或命名按键（`Enter`、`C-c`、`Up`…），单次 ≤ 4 KiB。
  - `pty_close`：SIGHUP → 2 s → SIGKILL（02 §6）；运行取消后 1 s 内进程组退出（07 §12.4）。
  - `assess`：`pty_open` 的 `approval_key` 与 `run_command` 同口径（08 §5.3；共用 `shell.rs`），`pty_read` 按只读口径报告。
- 不做：
  - 沙盒内 PTY 的规则接线（P07-05 的 `/dev/tty` 项）与审批（P07-02）。
  - Windows（`HostCap::Pty = Missing`，不编译；00 §5 平台范围）、滚动缓冲与鼠标协议等其它终端能力。

## 接口草案

草案，以实现为准。

```rust
// gqy-tools/src/pty_registry.rs（会话级；注入点见「风险与回退」）
pub struct PtyRegistry { /* session → PtySession 列表；注入 Clock 与取消令牌 */ }
impl PtyRegistry {
    pub fn open(&self, ctx: &ToolContext, cols: u16, rows: u16) -> Result<PtyHandle, ToolError>;
    pub fn session(&self, ctx: &ToolContext, id: PtyId) -> Result<Arc<PtySession>, ToolError>;
    pub async fn close(&self, id: PtyId, reason: CloseReason) -> Result<(), ToolError>;
}

// gqy-tools/src/screen.rs
pub struct Screen { /* vt100 仿真 */ }
pub fn snapshot(screen: &Screen) -> String;   // 渲染后的文本，不含转义序列

// gqy-sys/src/pty.rs
pub fn capability() -> HostCapState;          // Pty: Available | Missing
pub async fn wait_quiet(session: &PtySession, wait_ms: u64, clock: &dyn Clock) -> QuietOutcome;
```

## 测试与守护

- **快照不含转义**：跑带颜色/清行的输出 → `pty_read` 返回渲染后的文本，断言无 `\e[` 序列（去掉仿真必红）。
- **上限**：第 5 个 `pty_open` → 明确错误（含当前数量与上限 4）；关闭后可再开。
- **空闲关闭**：TestClock 推 31 min → 空闲会话被关闭；有活动则保留。
- **关闭流程**：被 `sleep 300` 占用的 PTY → `pty_close` 后 2 s 内进程组退出（pid 探测）；取消运行 → 1 s 内退出。
- **按键**：`Enter`/`C-c`/`Up` 的字节序列正确（对一个回显程序断言）。
- **能力缺失**：模拟 `HostCap::Pty = Missing` → 四个工具都不进工具面（`compile_surface` 断言）。
- 先红后绿对照（PR 贴输出）：把快照换成原始字节流、去掉空闲关闭各一次。
