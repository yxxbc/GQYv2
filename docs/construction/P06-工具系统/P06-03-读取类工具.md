## 目标

第一批真实工具落地：`read`（含域路径）、`glob`、`grep`、`read_output`。做完之后，模型可以在工作区里读文件（有明确上限、超出被标注截断）、按模式找文件、做进程内正则搜索，并能用 `read_output` 按范围取回被截断输出的全文；所有文件路径只经一个解析函数（`guard.rs`，初版；P07-04 原地强化为最终守卫）。

## 范围

- 做：
  - `StorageDomain`/`DomainTable`（07 §9.1 的 trait 与注册位）：本单注册「工作区」与 `out:`；`artifact:`/`kb:`/`history:`/`skill:` 由各自提供者在组装处登记，未注册前缀如实报 `unsupported` 并列出可用前缀。
  - `read`：`offset`/`limit`；单次 ≤ 50 KiB、≤ 2,000 行、单行 > 2,000 字符截断并标注；二进制（前 8 KiB 含 NUL）拒绝并报 mime 与大小；图片产出 `ToolContent::Image`（是否上送由 06 的画像决定）；目录返回错误并提示用 glob。
  - `glob`：模式匹配 + `.gitignore` 语义；按 mtime 倒序；≤ 1,000 条，超出报总数。
  - `grep`：进程内正则（不依赖 PATH 上的 `rg`）；`output_mode` = files / content / count；≤ 200 个匹配或 100 个文件；30 s 超时。
  - `read_output`：读 `out:` 域（本会话某次调用的输出全文），按字符范围取回；截断标记里的 `out:` 引用必须能回取。
  - `guard.rs` 初版：唯一路径解析函数（相对工作区根、拒绝 NUL 与 `..`、按组件比较判根内、拒绝符号链接指向根外——**只做到「不跟随」**，不做 realpath/openat2）；文件头注释标明「P07-04 之前的初版」。
- 不做：
  - 最终路径守卫语义（realpath、保护路径、TOCTOU、`openat2`）——P07-04；本单的用例集与 P07-04 的用例集分开写。
  - `kb:`/`history:`/`skill:`/`artifact:` 域本体（P12/P08/P13）。
  - 写入类工具（P06-04）、命令与 PTY（P06-05/P06-06）。

## 测试与守护

- **read 上限**：50 KiB、2,000 行、单行 2,000 字符三个边界各一例；`SelfBounded` 不被二次截断（07 §8）。
- **read 拒绝与提示**：二进制报 mime 与大小；目录 → 提示 glob；`offset` 越界报期望与实际。
- **域路径**：`out:<call>` 可读；未知前缀报 `unsupported` 并列出可用前缀。
- **glob**：`.gitignore` 生效、mtime 倒序、1,001 条时报总数、非法模式报错。
- **grep**：files/content/count 三模式；200 匹配 / 100 文件上限；超时用 TestClock 推时；二进制文件跳过并计数。
- **路径解析初版**：`..`、NUL、根外路径拒绝；符号链接指向根外时拒绝（不跟随）。
- **截断回取**：截断输出 → `read_output` 按范围取回，字节与原文一致。
- 先红后绿对照（PR 贴输出）：去掉行数上限、去掉 `out:` 域解析各一次。
