## 目标

回合与运行路由就位：提交返回 202 + `Admission` 四态；运行详情与运行树；取消幂等；问题列表与回答（409 语义 + 回答者校验）；会话授权列表与撤销。`Idempotency-Key` 的 24 小时语义落库。

## 范围

- 做：
  - `POST /sessions/{id}/turns`：网关推导 `Venue`/`Principal`（12；请求体里的 `venue` 一律忽略）→ 构造 `TurnRequest`（`mode` = Queue/Steer/Interrupt、`model` 仅本回合覆盖、`client_request_id`）→ 幂等检查（`Idempotency-Key` 或 `client_request_id`）→ `Supervisor::submit` → **202** + `Admission` 投影（`Started` / `Queued{position}` / `Steered{into}` / `Rejected{kind,code,message}`；Rejected 仍是 202，Q-13-3 已定）。
  - 幂等：`idempotency_keys` 落库（10 §7.6）；同键同体（blake3 规范化请求体一致）→ 返回首次的状态码与响应体；同键异体 → 409 `idempotency_key_reuse`；超过 24 小时视为新请求。
  - `GET /sessions/{id}/turns`：回合列表（终态与用量摘要；游标分页）。
  - `GET /runs/{run}`（状态、终态原因、父运行、用量）与 `GET /runs/{run}/tree`（父子与子代理会话；子代理未实现前是单节点树，字段照 13）。
  - `POST /runs/{run}/cancel`：体可带 `reason`；**已终态 → 200 + `already_terminal: true`**（不报错）；转发 `SessionCmd::Cancel`（取消树在 P04-05）。
  - `GET /sessions/{id}/questions`；`POST /questions/{qid}/answer`：体 `Answer`（`Approval{decision,note}` / `Ask{answers}` / `Dismiss`）；已答或已关 → 409 `Conflict` 并带当前状态；回答者校验（M 不能答 O 会话，08 §5.6）；回答写入审计（08 的 `audit_log`）。
  - `GET /sessions/{id}/grants` 与 `DELETE /sessions/{id}/grants/{grant}`：撤销立即生效（以 `call_id` 引用即刻失效；P06/P07 前断言接口层行为）。
- 不做：
  - SSE 推送（P05-08；本单的验证走 JSON 接口）。
  - 审批与提问的**界面**（P09/P10）与工具执行（P06/P07）。
  - 子代理与作业路由（P13）；用量汇总路由（`/usage`，随 P13/P01 就位）。

## 测试与守护

- **准入四态**：空闲 → `Started`；忙碌 → `Queued{position}`；`Steer` → `Steered`；队列满 → `Rejected{queue_full}` 且 HTTP 202。
- **幂等三态**：同键同体 → 同状态码同响应体；同键异体 → 409 `idempotency_key_reuse`；过期（TestClock 推 25 h）→ 新请求。
- **取消**：运行中 → 202/200 并进入 `Cancelled`；已终态 → 200 + `already_terminal: true`；重复取消幂等。
- **问题**：回答一次生效；第二次 409 且带当前状态；M 回答 O 会话 → 403；`Dismiss` 的语义（Ask 视为无回答、Approval 视为 Deny）。
- **授权撤销**：撤销后接口层立即可见（列表缺失；后续调用被拒的端到端断言留 P06/P07）。
- **Venue 忽略**：请求体带 `venue` 字段被忽略（真实 venue 由 Caller 推导）。
- 先红后绿对照（PR 贴输出）：把幂等检查去掉、把 `already_terminal` 改成 409 各一次。
