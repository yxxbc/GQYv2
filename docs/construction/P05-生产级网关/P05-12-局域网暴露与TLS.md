## 目标

局域网访问按设计上线：**默认关闭**；开启后强制 TLS（配置校验拒绝“局域网 + 明文”）；证书两种来源（自签自动生成与轮换 / 用户 PEM 与热加载）；启动与 `gqy doctor` 打印指纹；ALPN 通告 `h2` 与 `http/1.1`；`Host` 白名单防 DNS rebinding（421）；`Secure` cookie 与真实 IP 限速在该模式下同样成立；开关与证书轮换写 `auth_events`。

## 范围

- 做：
  - `tls.rs`：`tokio-rustls` 的 acceptor（rustls `ring` 后端）；ALPN = `h2` + `http/1.1`；握手超时（`gateway.tls.handshake_timeout_ms`，默认 10000）；作为连接包装接进 P05-02 的 accept 循环（同一 Router、同一中间件栈）。
  - `cert.rs`：
    - `auto_self_signed`（默认）：`rcgen` 生成，SAN 覆盖 `localhost`、`127.0.0.1`、`::1`、主机名与当前局域网地址；有效期 397 天；到期或 SAN 不再覆盖当前地址 → 自动重签，日志与 `auth_events.tls_cert_rotated` 记录指纹变化；私钥 `config/tls/gqy-key.pem`（0600）、证书 `config/tls/gqy-cert.pem`。
    - `files`：用户 PEM（`gateway.tls.cert_path` / `key_path`）；配置热加载时重载；加载失败保留旧证书并告警，**不中断服务、不降级明文**。
    - 指纹：SHA-256，启动与 `gqy doctor` 打印。
  - `lan.rs`：`gateway.lan.enabled`（默认 false）、`gateway.lan.listen`（默认 `0.0.0.0:8310`）、`gateway.lan.require_tls`（不可关）；配置校验：开启且未启用 TLS → 启动失败并写清期望与实际；`Host` 白名单（监听地址 + `gateway.http.allowed_hosts` + 默认本机名）→ 不匹配 421；开/关写 `auth_events.lan_enabled/lan_disabled`。
  - 与 P05-04/P05-05 的衔接：TLS 请求的 cookie 加 `Secure`；限速按 §8.5 的真实 IP（LAN 直连即 `ConnectInfo`）。
- 不做：
  - mesh、设备配对、双向 TLS、跨设备同步（17）。
  - 连接器端点自身的 TLS 细节（16；连接器连的是本机 UDS 或用户反代）。
  - 反向代理后的传输安全（用户自理）。

## 测试与守护

- **握手**：明文连 TLS 端口 → 被拒；ALPN 协商到 `h2`；握手超时（不发 ClientHello 的裸连接 → 超时关闭，计数）。
- **证书**：指纹稳定（同一证书重读一致）；SAN 覆盖 `localhost` 与当前地址；`TestClock` 推 398 天 → 重签 + `tls_cert_rotated` 一行；地址变化导致 SAN 不再覆盖 → 重签。
- **files 模式**：加载失败（坏 PEM）→ 保留旧证书并告警（服务不中断）；热加载成功后新指纹生效。
- **配置校验**：`lan.enabled=true` 且 `require_tls=false` → 启动失败（错误写期望与实际）。
- **Host 校验**：伪造 `Host` → 421；默认集合（本机名/回环）通过；LAN 地址在白名单内通过。
- **审计**：开/关各一行 `lan_enabled/lan_disabled`。
- **限速与 IP**：LAN 直连下按 `ConnectInfo` 计数；伪造 `X-Forwarded-For` 不影响（§8.5）。
- 先红后绿对照（PR 贴输出）：把 ALPN 去掉、把 SAN 判定改成恒真各一次。
