## 目标

`subagent` 工具与引擎的 `SpawnSubturn` 效果就位：子代理由工具产出 `ToolEffect::SpawnSubturn(SubturnSpec)`，引擎在父运行的 `ExecutingTools` 组中构造 `TurnRequest{ parent: Some(ParentLink), venue: Subagent, mode: Queue }` 并经 `Supervisor::submit` 提交——没有旁路；子会话是隐藏的审计会话（`SessionKind::Subagent`），有自己的账本、前缀链与冻结工具面；场所 `Subagent` 的 trust / caps 只能收窄不能放大；子运行的取消令牌是父工具调用令牌的子令牌（父取消 → 子 1 s 内终止）；终态后最后一条 assistant 文本作为父调用的工具结果（附 `subagent_session` 与终态；失败写失败分类，不让父运行失败）；`background = true` 立即返回 `Job started: <JobId>`（复用 P13-02）。深度 1（上限 3）、每父并发 4（上限 8）、全局池 8（上限 32）都有固定文案与等待语义。

## 范围

- 做：
  - `subagent` 工具：参数 `task` / `tier` / `background` / `resume_id`（v1 同名）；描述为**常量字节**（不随配置插值）；`Lazy` 驻留；效果 `SpawnSubturn`；深度已达上限时不出现在子回合的工具面（该面自己的事，与父字节无关，07 §10）。
  - 引擎执行分支：组内遇到 `SpawnSubturn` → 构造 `TurnRequest`；每父并发 ≤ 4（多出的调用在组内排队等待）；全局子代理池 8（`Queued` 等许可，从独立池取，不与父互等——死锁回归）。
  - 子会话：`SessionKind::Subagent` + `hidden = true`；元数据记录 `parent_run` / `parent_call` / `depth`；`resume` 续接同一子会话；工具面 = 父会话冻结面 − `ask_user` + 按 `tier` 限制；模型绑定按 `tier` 在同一供应商配置中解析（06 §10），未指定时与父相同。
  - 场所收窄：`Venue{ kind: Subagent, trust: 父 trust, caps: 父 caps ∩ 子代理档案, interactive: false }`；principal 继承父会话。
  - 生命周期：父取消 → 子令牌取消（1 s 内终态）；深度超限返回固定文案 `Subagent depth limit reached (max N).`；子运行失败时工具结果写明失败分类，父继续执行。
  - 结果与申诉：结果 = 最后 assistant 文本 + `subagent_session` + 终态；超长按 05 §10 截断；审批冒泡——父场所可交互时 `question.asked` 带 `origin_run` 转发到父会话问题通道并标注来源，父不可交互时按父场所规则拒绝（08 §5.5）。
  - 审计：父账本工具条目记录 `child_session` / `child_run`；`GET /runs/{id}/tree` 能还原整棵运行树（13 §5.3 核对）；子会话保留 `subagent.trace_days`（默认 7 天）后由保留作业删除并发 `session.expired`，被用户固定的除外。
  - 事件：`subagent.started` / `subagent.finished`（父流）；子运行详细事件在子会话流（复用既有目录）。
  - 配置：`subagent.max_depth` = 1（上限 3）、`subagent.per_run_concurrency` = 4、`subagent.global_pool` = 8、`subagent.trace_days` = 7 落进 `gqy-config`。
- 不做：
  - 作业调度本体（P13-02；`background` 只调用其接口）；
  - 深度 > 1 的默认行为（Q-03-2 拍板前默认 1，仅配置可放宽到 3）；
  - TUI 的子代理详情视图（14 §8.3 已有设计，界面另开单）；子代理专用的审批界面。

## 测试与守护

- **深度**：默认 1 时子回合工具面里没有 `subagent`；配置放宽到 2 后才有；超限返回固定文案（去掉判断，红）。
- **取消传播**：父取消 → 子运行 1 s 内终止（暂停时钟）；去掉子令牌接线，红。
- **死锁回归**：全局回合许可占满时子代理仍能完成（从独立池取许可，03 §16）；改成从全局池取，红。
- **收窄**：子场所 trust / caps 不超过父（属性测试：caps 交集、trust 继承）；放大时测试红。
- **结果回传**：子失败 → 父工具结果写失败分类且父继续运行；超长结果带 05 §10 的截断标记。
- **审批冒泡**：父可交互 → `question.asked{origin_run}` 且回答路径走父会话；父不可交互 → 按父场所规则拒绝并发 `question.unanswerable`。
- **审计保留**：快进 7 天 → 子会话被清除 + `session.expired`；固定会话不被清除。
- 先红后绿对照（PR 贴输出）：去掉子令牌、去掉深度判断各一次。
