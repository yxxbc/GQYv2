# P13 · 扩展体系

> 状态：【规划】。本阶段把 18 号设计落成：SubsystemHooks 正式化、持久化作业与定时器、子代理、技能、脚本工具、MCP stdio 客户端、扩展包管理。红线：扩展不能破坏字节契约（钩子产出只追加到尾部并化石化），不能扩大权限（声明 ∩ 场所上限 ∩ 会话档位 ∩ 审批）；扩展代码全部作为子进程运行，不在 daemon 进程内执行第三方代码。
> 创建：AI 助手（Cline 会话），2026-09-28。改动本文件时，按根 `AGENTS.md` 规矩 7 更新这一行：写清谁改的、什么时候改的。

## 阶段目标

（与施工图 `plan-data` 同文）SubsystemHooks、技能、脚本工具、MCP、子代理、持久化作业与定时器、扩展包。做完之后：

- 钩子只有三个调用点（`before_request` / `after_turn` / `on_evict`），输出只能成为 `Channel::Context` 尾部块并化石化；注入顺序按 `(hook.id, 块序)` 确定、与完成先后无关；超时、失败、panic 都“什么都不注入”，不碰已有前缀（18 §3）；
- 作业与定时器是内核能力：`Exec` 前台软超时转作业不丢回合、`job_*` 四工具可用、`WakePolicy::OnFinish` 唤醒、持久化定时器带 `CatchUp` 与时钟跳变处理（03 §10）；`work_items` 提供领取 / 租约 / 退避 / 重启恢复，P12-05/06 与保留车道直接消费（10 §7.4）；
- 子代理是普通回合：带 `parent` 走同一准入，隐藏审计会话、场所只收窄、结果回传父调用，深度 / 并发 / 池都有上界（03 §9）；
- 技能是提示文本 + `load_skill` + `skill:` 只读域；脚本工具从头部声明编译进 `ToolSource`；MCP 的专用读任务与每请求超时在结构上消灭 v1“read_line 占住唯一执行线程”的故障；工具面只读持久化列举缓存，server 离线时 stub 照常冻结（18 §6.5）；
- 扩展包 = 目录 + 清单 + 锁文件：内容哈希、能力声明确认、升级扩大能力必须再次确认；扩展数据在 `extensions-data/<name>/`，不直接写 `gqy.db`（18 §7.3）。

## 遗留与发现

> 施工过程中发现的范围外问题记在这里；写单时发现、需要用户拍板的点也记在这里。

写单时的口径：

1. **结构固定**：每张单按施工总纲 §3.2 写——表头（`| 状态 | 未开始 |`、依赖、`| 设计依据 |`、`| 规模 |`、`涉及 crate / 目录`）＋ 固定九节（`## 目标`、`## 范围`、`## 改动清单`、`## 接口草案`、`## 实施步骤`、`## 测试与守护`、`## 验收流程`、`## 完成判据`、`## 风险与回退`）；表头之后加一行「草案（开工前复核）」；状态以单文件头为唯一真相源，本 README 只写链接与一句话。
2. **待定项按推荐先行**：Q-18-1（内容哈希 + TOFU + 能力确认，签名后置）、Q-18-2（无分发索引）、Q-18-3（扩展包不能提供钩子）、Q-18-4（workspace 技能默认关）、Q-18-5（只 stdio）、Q-18-6（MCP 默认 `none` + doctor 警告）。拍板前不实现相反行为。
3. **扩展不扩权（铁律 7、8）**：脚本与 MCP 的效果类别默认最高后果（`exec`）；`network` 声明当前无法强制（Linux 沙盒不管网络），doctor 与安装确认必须如实写；扩展的实际权限 = 声明 ∩ 场所上限 ∩ 会话档位 ∩ 审批。
4. **收窄方向的依赖**：Memory / KB 钩子（P12）与扩展工具都只能收紧场所能力；任何“扩展绕过 08 判定”的实现视为设计错误，先改 18 / 08 再动手。
5. **不在本批 7 张单内**：伴侣功能的扩展包实现（18 §8，逐项由用户决定优先级）；签名与 `gqy ext trust`（Q-18-1 第二阶段）；扩展商店 / tap（Q-18-2）；MCP HTTP 传输（Q-18-5）；TUI / Web 的扩展管理界面。

**开工前复核清单**（00 §5 的「并入」项与跨文档不一致；先改设计文档、再开工）：

1. **`load_skill` 的落点**：18 §4.3 要求它是 Lazy 工具，但 07 §10 的内核工具表没有这一行；P13-04 以 `gqy-ext` 的 `ToolSource("skills")` 形态提供，开工前在 07 §4.2 / §4.3 注明来源与命名（`skill:` 域已登记在 07 §9.1）。
