## 目标

技能成为“提示文本 + 只读资源”的扩展：`SKILL.md` 的 YAML frontmatter 按上限解析（`name` 与目录名一致、`description` ≤ 300 字符、`license` / `compatibility` / `metadata` 原样保存），非法或超限的技能不进索引、doctor 报行号与原因、不影响其他技能；三个可信来源（built-in / global / persona）按 `persona > global > built-in` 覆盖；`skills-index` 节由 P11-06 的接缝消费，在会话创建（或代际切换）时渲染一次并冻结（按 name 排序、≤ `index_max_bytes`，超出截断并在块尾写 `+N more; use load_skill with list=true`）；`load_skill {name}`（Lazy 工具，`ToolSource("skills")`）返回剥离 frontmatter 的正文作为 tool result 进入尾部——**新增技能对当前会话只经 `list=true` 的结果可见，不碰前缀**；资源文件用 `read skill:<name>/<path>` 读取（只读域，路径守卫拒绝 `..` 与绝对路径）。

## 范围

- 做：
  - 解析器：`SKILL.md` frontmatter（token ≤ 4,096，文件 ≤ 256 KiB，目录 ≤ 200 文件 / 8 MiB）；未知字段原样保留；错误带行号与原因。
  - 来源与覆盖：built-in（编译进二进制）、`<data>/extensions/skills/`、`<data>/personas/<p>/skills/`；同名覆盖优先级与冲突列表进 `gqy doctor`；工作区技能不启用（Q-18-4，默认关且无开启路径）。
  - 索引渲染：`render_skills_index` 纯函数，按 name 排序、总长上限、`+N more` 截断文案；接入 P11-06 的 `skills-index` 接缝（会话创建 / 代际切换时一次性渲染并冻结）。
  - 工具：`load_skill {name}`（正文）与 `{list: true}`（目录，尾部结果）；未启用 / 不存在的技能返回同一形状的英文错误（不含存在性差异之外的内部路径）。
  - 存储域：`skill:` 只读提供者（`read skill:<name>/<path>`），只允许读本会话 persona 启用的技能；路径规范化拒绝逃逸；二进制与体积限制照 07 §10 的 `read` 契约。
  - 扫描在后台：目录变化去抖后刷新来源快照（P13-07 的刷新入口接入），不在回合路径上（07 §4.2）。
  - 配置：`[skills].workspace_skills` = false、`[skills].index_max_bytes` = 6144 落进 `gqy-config`。
- 不做：
  - 工作区技能开启路径（Q-18-4 拍板前不做）；
  - 扩展包安装与来源刷新本体（P13-07）；
  - `skills-index` 节的渲染代码（P11-06 已有）；
  - 技能内脚本自动成为工具（设计明确禁止：脚本单独声明才成工具，见 P13-05）。

## 接口草案

草案，以实现为准。

```rust
pub struct SkillMeta { pub name: String, pub description: String, pub scope: SkillScope }

/// 解析 frontmatter：未知字段原样保存；超限 / 非法返回带行号的错误。
pub fn parse_skill_md(bytes: &[u8]) -> Result<(SkillMeta, String /*正文*/), SkillError>;

/// 确定性渲染：按 name 排序；超出 max_bytes 时按序截断并追加 `+N more; use load_skill with list=true`。
pub fn render_skills_index(skills: &[SkillMeta], max_bytes: usize) -> String;
```

## 测试与守护

- **索引确定性**：同一技能集合渲染 100 次字节相同；输入顺序打乱结果不变；改成按目录顺序输出，红。
- **冻结**：会话创建后新增技能 → 当前会话 system 字节不变；`load_skill{list:true}` 能列出（尾部结果）。
- **上限**：4,096 token、256 KiB、200 文件 / 8 MiB、6 KiB 索引截断与 `+N more` 文案各一例；去掉截断，红。
- **非法 frontmatter**：只影响该技能，其他技能照常进索引；doctor 含行号与原因。
- **域守卫**：`skill:a/../../x` 与绝对路径被拒；未启用技能不可读（两条用例）。
- **英文**：`load_skill` 的 stub 摘要 ≤ 60 字符且全英文（19 §6.1 门禁）。
- 先红后绿对照（PR 贴输出）：去掉索引截断、去掉域路径守卫各一次。
