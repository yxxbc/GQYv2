# P15 · 设备共享

> 状态：【规划】。本阶段把 17 号设计落成 `gqy-mesh`：设备身份与证书、局域网发现、全员同意配对与撤销、能力委派、同步合并、跨设备前缀交接验证、服务器角色与自动降级。红线：无账户体系（信任靠配对密码建立、成员账本是唯一事实）、传输只用 HTTPS（证书按公钥钉扎）、裁决留在提供方、每个会话只有一个主场设备、合并由用户决定（append-only 让合并退化为并集、冲突变成分叉）。

## 阶段目标

（与施工图 `plan-data` 同文）发现、全员同意配对、TLS 信任、能力委派、同步合并、跨设备前缀交接。做完之后：

- 每台设备生成 Ed25519 身份（`<data>/mesh/device.key`，0600，永不同步、不进导出）；`DeviceId` = 身份公钥 SPKI 的 blake3 前 16 字节（32 hex）；TLS 证书自签发（10 年），**信任对象是公钥而不是证书**（17 §5.1、§5.6）；
- mesh 默认关（`mesh.enabled = false`，D-03 已定）；开启后 mDNS 广播与浏览 `_gqy._tcp.local`，TXT 只用于列出候选、身份以 TLS 公钥为准；组播不可用时支持手动 `host:port`（17 §4）；
- 新设备加入需**全部成员同意**：PAKE（口令 = 网格密码，不落盘）+ 双方公钥指纹绑定防中间人；离线成员挂起等待（7 天过期）；任一成员可撤销任一成员，撤销后 1 秒内新 TLS 握手失败、已有连接关闭（17 §5.3–§5.5）；
- 能力委派：A 的会话把 B 的能力作为远程工具 `device_<name>.<tool>` 使用（会话创建时冻结进工具面）；**B 的权限引擎裁决**（A 只能收紧不能放宽）；需要审批时推送到 A 的会话流、B 本机同时可见；B 下线后工具面字节不变、调用返回 `device_offline`（17 §6）；
- 同步只在用户确认后进行：heads → 差异计划 → 分页拉取 → 逐条校验哈希链 → 经 store 单写者应用；一方是另一方前缀则追加，冲突从最后公共 seq 起写成新会话（`session.forked`）；不修改本机已有条目（17 §7）；
- 跨设备前缀交接按研究项验证：同版本重建的第 N 轮请求字节与 `prefix_hash` 一致则缓存可续，否则显式 `DeviceHandoff` 冷启动；结论写回 17 §8；
- 服务器角色（`auto` / `server` / `client`）与自动降级成立：服务器不可达时本机 host 接管，服务器上的会话只读、继续即本机分叉（17 §3）。

## 遗留与发现

> 施工过程中发现的范围外问题记在这里；写单时发现、需要用户拍板的点也记在这里。

写单时的口径：

1. **结构固定**：每张单按施工总纲 §3.2 写——表头（`| 状态 | 未开始 |`、依赖、`| 设计依据 |`、`| 规模 |`、`涉及 crate / 目录`）＋ 固定九节（`## 目标`、`## 范围`、`## 改动清单`、`## 接口草案`、`## 实施步骤`、`## 测试与守护`、`## 验收流程`、`## 完成判据`、`## 风险与回退`）；表头之后加一行「草案（开工前复核）」；状态以单文件头为唯一真相源，本 README 只写链接与一句话。
2. **默认关**：`mesh.enabled = false` 是默认（17 §11）；本阶段的全部能力在默认配置下没有网络面；「单机使用时不启用 mesh 监听」照 01 的理解（17 §2）。
3. **无账户体系与边界诚实**：设备间信任只有成员账本一条来源；设备名、TXT、ping 应答都是不可信展示信息。一台设备被攻破 = 攻击者获得该设备在网格中的全部授权；缓解靠撤销与提供方裁决（17 §10），如实写进用户文档。
4. **浏览器不直连 mesh**：浏览器只访问本机网关，由本机 host 代理远程请求（17 §5.6）。
5. **待定项按推荐先行**：Q-17-1（离线成员挂起等待，7 天过期）、Q-17-2（任一成员可撤销任一成员）、Q-17-3（版本不一致按 17 §9 表）、Q-17-4（凭据默认不同步、改为委派）、Q-17-5（PAKE 评估后拍板）、Q-17-6（主场迁移不进第一版）。拍板前不实现相反行为。
6. **不在本批 7 张单内**：TUI / Web 的设备与配对界面；模型接入委派（Q-17-4 的落地形态）；记忆 / 知识库 / 硬件类别的委派（17 §6.1 其余行）；公网穿透与中继（非目标）；工作区文件同步（非目标）；主场迁移流程本体（Q-17-6，P15-06 只做验证工具与结论）；桌面宿主的 mesh 联测（P16-06 / P16-07）。
