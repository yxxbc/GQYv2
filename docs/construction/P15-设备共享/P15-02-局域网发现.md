## 目标

mesh 开启时设备在局域网可被发现：mDNS/DNS-SD 广播与浏览 `_gqy._tcp.local`（端口 = `mesh.listen`），TXT 记录 `id / name / mesh / proto / ver / pair`；TXT 解析容忍缺字段与未知字段，内容一律视为不可信、只用于列出候选，身份以 TLS 握手公钥为准（P15-01）；组播不可用的网络支持手动输入 `host:port`；`mesh.discovery = false` 关闭广播与浏览、手动路径仍可用；发现全程不产生任何信任。

## 范围

- 做：
  - 广播注册与浏览；实现可替换（真实 mDNS 与测试假发现共用 trait，测试不依赖网络）。
  - TXT 生成与解析（夹具覆盖全字段 / 缺字段 / 未知字段）；解析失败只丢该候选，不 panic。
  - 候选合并与去重：同 `DeviceId` 来自 mDNS 与手动时合并为一条、来源列表保留两者。
  - `gqy mesh discover`（列出候选：来源、地址、TXT 展示字段；不发起连接）；`--addr <host:port>` 手动输入（复核第 5 条的最小 CLI）。
  - 配置 `mesh.discovery`（17 §11）。
- 不做：
  - 配对与信任（P15-03；本单任何输出都不构成信任）。
  - 界面（另单）；UDP 广播等其它发现机制（17 §4 未定义）；`pair` 标志的行为（只透传展示）。

## 接口草案

草案，以实现为准。

```rust
pub struct Candidate { pub source: CandidateSource, pub addr: SocketAddr, pub txt: CandidateTxt }
pub enum CandidateSource { Mdns, Manual }
/// TXT 六字段均可缺失；未知字段忽略；内容是不可信展示信息（17 §4）。
pub struct CandidateTxt {
    pub id: Option<String>, pub name: Option<String>, pub mesh: Option<String>,
    pub proto: Option<String>, pub ver: Option<String>, pub pair: Option<bool>,
}
pub trait Discovery: Send + Sync {
    fn start(&self, announce: AnnounceRecord) -> Result<(), MeshError>; // announce.port = mesh.listen
    fn stop(&self);
    fn candidates(&self) -> Vec<Candidate>;
    fn add_manual(&self, addr: SocketAddr);
}
```

## 测试与守护

- **TXT 往返**：全字段 / 缺字段 / 未知字段 / 非法 `id` 不 panic；与 17 §4 字段表逐项对照（改字段名，红）。
- **默认关**：`mesh.enabled = false` 或 `mesh.discovery = false` 时假发现实现断言没有注册（去掉判断，红）。
- **去重**：同 `DeviceId` 的 mDNS 与手动来源合并为一条、来源列表保留两者（去掉合并，红）。
- **不可信**：候选的 `name` / `id` 不进入任何信任判定（与 P15-01 的 TLS 用例联测一条：TXT 谎报不改变握手结果）。
- 先红后绿对照（PR 贴输出）：让广播无视 `mesh.discovery` 一次。

## 风险与回退

- **企业网络屏蔽组播**：手动路径兜底（17 §4）；发现不可用不阻塞配对（P15-03 支持手动地址直连）。
- **TXT 泄露面**：只放设备名与版本；用户可关广播（17 §10）。
- **回退**：`mesh.discovery = false` 或 `mesh.enabled = false`，无数据影响。
