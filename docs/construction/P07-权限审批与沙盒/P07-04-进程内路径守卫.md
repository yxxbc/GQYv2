## 目标

把 P06-03 的初版 `guard.rs` 强化成 08 §6.1 的最终守卫：组件比较、realpath 最长前缀、`..` 拒绝、保护路径（任何档位、含 `Full`）、`openat2(RESOLVE_BENEATH | RESOLVE_NO_MAGICLINKS)` 或「打开后 fstat 比对 dev/ino」回退。做完之后，符号链接逃逸、`..` 逃逸、`/work2` 与 `/work` 前缀混淆、大小写不敏感文件系统上的绕行都被拒；写入不跟随目标符号链接。

## 范围

- 做：
  - 五步照 §6.1：拒绝含 NUL；对已存在的最长前缀做 realpath（解析符号链接）再拼接剩余部分并拒绝其中的 `..`；与读根 / 写根 / 保护路径**按路径组件**比较；打开文件优先 `openat2`（Linux 5.6+），无 `openat2` 时回退「规范化 + 打开后 `fstat` 比对 dev/ino」，并在 `gqy doctor` 标注「路径守卫存在 TOCTOU 窗口」；写入用同目录临时文件 + rename，不跟随目标本身是符号链接的情况。
  - 保护路径照 §4.1：GQYv2 数据目录中除存储域外的全部内容（`gqy.db`、`blobs/`、`config/`、`run/`、`logs/`）、`~/.ssh`、`~/.gnupg`、`~/.aws`、`~/.config/gh`、`~/.netrc`，加 `permission.protected_paths`；对 `Full` 同样生效。
  - 读根 / 写根与三个配置项：`extra_read_roots`、`extra_write_roots`、`read_anywhere`（仅 Owner；Member 永远 false）。
  - 域路径例外：`artifact:` / `kb:` / `out:` / `history:` / `skill:` 不走文件系统守卫（07 §9.1）；守卫只作用于无前缀路径。
  - `gqy-sys`：`openat2` 原语与可用性探测（能力查询，不在业务 crate 里写平台分支，08 §6.5）。
- 不做：
  - Landlock 与 macOS 沙盒（P07-05 / P07-06）。
  - Windows 的完整路径语义（08 §6.5：不能证明根内就拒绝——那条规则在本单的组件比较里生效，盘符 / UNC 的完整处理不在第一版）。

## 接口草案

草案，以实现为准。

```rust
// gqy-tools/src/guard.rs（08 §6.1；唯一实现）
pub enum Access { Read, Write }
pub fn resolve(scope: &WorkspaceScope, cfg: &ConfigSnapshot, rel: &str, access: Access)
    -> Result<ResolvedPath, GuardError>;
pub fn open_beneath(resolved: &ResolvedPath, access: Access)
    -> Result<std::fs::File, GuardError>;          // openat2 优先，fstat 回退
pub enum GuardError { Nul, OutsideRoot, Protected { path: PathBuf }, SymlinkEscape, Io { errno: String, path: PathBuf } }
```

## 实施步骤

1. 五步的第 1–3 步（NUL、realpath、组件比较、保护路径）——先写 08 §11 的四条会红用例。

5. `cargo xtask check --fast`、`cargo test -p gqy-tools -p gqy-sys`；提交：`feat(perm): 进程内路径守卫`。

## 测试与守护

- **符号链接逃逸**：工作区内链接指向 `/etc` → 拒绝（去掉 realpath 步骤必红）。
- **`..` 逃逸**与 **`/work2` vs `/work`** 前缀混淆（按组件比较，字符串前缀必红）。
- **大小写不敏感（macOS）**：`WORKSPACE/../Workspace` 一例（在对应平台跑）。
- **保护路径**：数据目录 `config/`、`run/`、`~/.ssh` 等各一例；`Full` 档位同样拒绝；`protected_paths` 追加项生效。
- **TOCTOU 标注**：回退路径下 doctor 文案出现；`openat2` 可用时消失。
- **域例外**：`out:` / `kb:` 不经守卫（断言守卫未被调用）。
- 先红后绿对照（PR 贴输出）：去掉保护路径判定、把组件比较改回字符串前缀各一次。
